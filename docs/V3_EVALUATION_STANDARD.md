# 后续模型统一评价口径

自 2026-10-30 起适用于屏障区、消落区及后续采样/集成对照。旧训练入口及其源码指纹不改写；单折与完整OOF均保留AP、ROC-AUC和C20。C20只需评分和面积，不依赖出图或自然断点。

## 固定指标

1. 排序：AP 为主要比较指标，ROC-AUC 辅助；同一空间折比较相同测试单元，随后报告逐折和完整 OOF。PR 曲线可以附图，不再将另一种积分定义的 PR-AUC 当作独立主指标。记录样本数量、滑坡数量及滑坡比例，避免直接以 AP 绝对值跨屏障区和消落区比较。
2. 成图：QGIS 自然断点五级，极低、低、中、高、极高。分别报告“中+高+极高”“高+极高”的滑坡覆盖率及面积占比，两者成对展示。另外报告沿评分排序达到 80%、90% 已知滑坡覆盖率所需的面积占比，作为统一覆盖水平下的描述性比较，不将其解释为独立验证得到的部署阈值。
3. BA：主 BA 固定以中及以上为易发、低和极低为低易发；辅助 BA 以高及以上为易发。BA = (TP/(TP+FN) + TN/(TN+FP))/2，同时保留混淆矩阵。这里使用预先声明的等级边界，不在测试标签上优化阈值；自然断点只能使用分数分布，不能根据滑坡覆盖率反复调断点。

测试集保留全部留出单元及原类别比例，不跟随训练样本配平。背景标签表示清单中未标注滑坡，指标均相对于现有清单。面积分母为实际评价的建模单元面积，不混入河道规则赋级单元。达到固定覆盖率时同分单元整体纳入，不依据标签拆分同分组。

评价按阶段执行：单折及未完成五折的探索阶段比较 AP、ROC-AUC 和 C20，不进行临时五级分区，也不使用同覆盖率面积比较。完成空间五折、汇集每个单元由其留出折模型生成的完整 OOF 评分后，再在 QGIS 中进行自然断点分级，统一计算等级覆盖率、面积占比、80%/90%覆盖所需面积和基于等级边界的 BA。OOF 全图评分不能替换为包含该单元训练样本的模型预测。

屏障区和消落区独立分级，县域沿用所属范围的统一分级边界。改变模型和采样比例可能改变分数尺度，必须记录各模型实际分级断点和面积。

## 独立评价入口

训练过程不增加拟合或改变预测；模型完成后再评价。单折示例（路径按实际实验替换）：

```bash
python -m src.v3.evaluation_standard \
  --predictions results/v3_ratio_barrier_s42_v2/subsample_p1_n2/fold0/predictions.csv \
  --out results/evaluation_barrier_1to2_fold0_rank
```

输出 ranking.csv（AP、AUC、样本数）；C20可继续读取训练的metrics.csv，或按同一累计面积规则计算。另输出 qgis_scores.csv。单折阶段使用AP、AUC和C20；没有等级文件时，不输出 BA、分级覆盖或同覆盖率面积比较。有完整 OOF 的 QGIS 等级文件后，额外输出 grade_metrics.csv 和 area_at_recall.csv。

以下分级评价留待完整 OOF 评分形成后执行。将完整 OOF 的 qgis_scores.csv 按 unit_id 连接至斜坡单元图层，以 score 在 QGIS 中进行自然断点五级分类。将实际等级写入整数 level（1极低、2低、3中、4高、5极高），导出仅包含本次评价单元的 CSV，保留 unit_id、score、level，score 使用足够精度。不要将其他模型的等级直接套用。下面命令仅展示参数形式；正式评价应替换为完整五折预测文件及全区等级表。

```bash
python -m src.v3.evaluation_standard \
  --predictions results/v3_ratio_barrier_s42_v2/subsample_p1_n2/fold0/predictions.csv \
  --grades /你的路径/barrier_1to2_fold0_qgis_grades.csv \
  --out results/evaluation_barrier_1to2_fold0_full
```

新增 grade_metrics.csv，minimum_level=3 对应中及以上，4 对应高及以上，包含覆盖率、面积占比、BA和混淆矩阵。入口核对评分、单元和等级顺序，防止错配旧等级。五折可给 --predictions 传入同一模式/种子的五个不重复预测表；等级文件对应完整 OOF。不同模式不能合并；同一单元的多个种子需先明确平均方案再评价。

该评价入口可对旧预测补算指标，不需要重跑模型。旧汇总 metrics.csv 本身不足以恢复 PR 排序、面积曲线或 BA，必须提供逐单元预测；分级指标还需要 QGIS 实际等级。
