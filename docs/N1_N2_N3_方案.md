## 1. N1 —— 校正的"充分性"与权重无关校正程序（旗舰，模型侧）

**主张**：教科书式 case-control / 先验校正（Prentice–Pyke 截距校正）**必要但不充分**；
给出①**充分性诊断**与②**权重无关**的校正程序，使不能吃 `sample_weight` 的模型也能产出对目标人群有效的概率。

| 项 | 内容 |
|---|---|
| **被推翻条件** | 若"设计匹配的加权"能把校准截距拉回 ≈0 且均值 p ≈ π，则"不充分"不成立 |
| **结构性空缺理由** | 需要**同一数据在多种抽样设计下**的对照概率与校准——常规研究只有一种设计（别人做不了） |
| **已有证据** | ✅ 偏移量取对（−2.025，与公式 −2.02 吻合）后，均值 p 仍为 π 的 **0.4×**、校准截距 **+0.69**（`results/target_population_audit.txt`） |
| **待补** | B2（XGB 三处理）、B3（TabPFN 三处理，含等渗重校准）、B4（排序位移分解） |
| **决策后果** | 改变图上每一级的风险数值与其可用人群 |

**两类正交校正（N1 的理论骨架）**

| | 输出侧（单调） | 设计侧（拟合） |
|---|---|---|
| 手段 | 截距校正 / 等渗重校准 | 重要性加权 / 上下文按目标人群重采样 |
| 能修 | 概率尺度（Brier、可靠性、净收益） | **排序与边界**（AUC、选中集合） |
| 不能修 | **排序**（单调变换不变） | —（但需要权重或能重采样） |
| 领域现状 | 部分做了（2006 年 rare events LR） | 只在能吃权重的模型上做了 |
| **空白** | **充分性诊断**（何时不够） | **权重无关适配（ICL）** |

## 2. N2 —— "口径盲报告"的决策代价（N1 的一章）

**主张**：不声明目标人群的报道会同时污染**概率量级**与**排序**，并在**决策**上产生可量化后果。

| 项 | 内容 |
|---|---|
| **被推翻条件** | 若各口径的决策后果一致（选中面积、净收益排序不随口径变化），则主张不成立 |
| **结构性空缺理由** | 同 N1（需多口径对照档案） |
| **已有证据** | ✅ Spearman **0.669**；前 10% 面积选中集合重合 **54.4%**；分级一致率 **38.3%**；同一名义阈值 p_t=0.02 下选中面积 **16.4%~73.2%（4.5×）**、p_t=0.20 下 **0.2%~9.6%（44×）** |
| **待补** | B5：**完整净收益曲线** + **等面积**下的覆盖/漏检率（可比口径）+ **α ↔ p_t 对应表** |

## 3. N3 —— 空间支撑改变的是"概率对谁有效"（支撑轴；MIL 的正确化身）

**主张**：观测支撑（斜坡单元 vs 像元袋）改变的是**概率的语义与目标人群**，而不是"AUC 涨多少"。

**三臂设计**（判读三种结果都能写）：

| 臂 | 输入 | 含义 |
|---|---|---|
| A | 38 维聚合量（现主线） | 基准 |
| B | 像元袋 + 像元坐标 | 组成 + 空间排布 |
| C | 像元袋 + **袋内像元打乱** | 只有组成，无排布 |

**判读**：B>C>A → 排布有信息；B≈C>A → 只需像元分布；B≈C≈A → **聚合不是瓶颈**（负结果同样可写）。

| 项 | 内容 |
|---|---|
| **判据** | 主指标 = 消落带内子集 AUC；**Δ > MDE 0.0069** 且两分折同号 |
| **被推翻条件** | 支撑效应 < MDE → 改述为"聚合已足够" |
| **现状** | 脚本就绪（`v2_build_unit_grid` / `v2_build_unit_bags` / `v2_model_mil`）；本地 GPU 可达；**预处理需 rasterio（本机被系统策略拦，需服务器或自写解码）** |
