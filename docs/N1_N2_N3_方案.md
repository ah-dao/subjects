## 0.5 研究现状核验（2026-10-12，第六轮检索）——**定位修正**

> 目的：在开工前最后确认 N1/N2/N3 是否真"前人未占有"。
> 结论：**N1 与 N3 的邻域比先前判断更拥挤**，N2 仍最站得住。下面按主张逐条给依据。

### 0.5.1 N1（校正充分性 + 权重无关程序）

| 检索发现 | 出处 | 影响 |
|---|---|---|
| 医学/统计侧**正在做** case-control 模型的校准 | [Calibration of cohort-based and case–control-based models（npj Digital Medicine 2026）](https://www.nature.com/articles/s41746-026-02624-3/figures/3) | ⚠️ "校正不足"不是我们的发现 |
| 回顾性 case-control 的**跨域校准**已有人做 | [Improved risk prediction via cross-domain calibration in a retrospective case-control study（Can. J. Stat. 2026）](https://onlinelibrary.wiley.com/doi/10.1002/cjs.70058) | ⚠️ 直接命中"标准校正不够、需重校准" |
| case-control 抽样的**加权框架**已成型 | [Unified Three-Stage Weighting Framework under Case–Control Sampling](https://arxiv-org.ezproxy.obspm.fr/html/2606.26543v1)、[Retrospective Causal Attribution under Case–Control Sampling](https://arxiv-org.ezproxy.obspm.fr/html/2609.07721v1) | ⚠️ 设计侧解法已被系统化 |
| ICL/表格基础模型的**校准与覆盖**正被抢 | [Conformal Prediction and Conditional Coverage for Tabular Foundation Models](https://browse-export.arxiv.org/pdf/2609.34887)、[Adaptive Noise Injection for Enhanced TabPFN Calibration](https://zenodo.org/records/20649431/files/paper.pdf?download=1) | ⚠️ 我们的"权重无关程序"窗口正在关闭 |
| 本领域 2006 年已有 rare events LR（先验校正） | Geomorphology 2006（见台账 C 区） | ❌ 校正本身在 LSM 早有 |

**修正后的 N1**：不再是"提出方法"，而是**领域翻译 + 一个窄程序**：
(1) 在 LSM 的多口径档案上量化"标准校正不足"（2 倍偏、校准截距 +0.69）——
**这是别人没有的数据条件**；(2) 给"不能吃样本权重"的模型一个可复现的**设计侧重采样 + 输出侧单调重校准**程序。
⚠️ 若 B3 显示该程序与既有等渗/共形做法等价，则**放弃方法主张**，只保留实证部分（归入 N2）。

### 0.5.2 N2（口径盲报告的决策代价）——**仍是最站得住的一条**

| 已知（被占） | 出处 |
|---|---|

| 编目规模敏感性 | Quat. Res. 2026（Koch 等） |

| **未检索到（可占有）** | 依据 |
|---|---|
| 把口径差异折算成**决策后果**（净收益 / 同一名义阈值下选中面积差 4.5~44×） | 检索未见 |
| 要求**声明目标人群**并给出可比口径（等面积下覆盖/漏检） | 检索未见 |

**结论**：N2 的**决策代价框架**是目前唯一"既有真实决策、又没人做过"的部分 → **建议升为旗舰**。

## 1. N1 —— 校正的"充分性"与权重无关校正程序（旗舰，模型侧）

**主张**：教科书式 case-control / 先验校正（Prentice–Pyke 截距校正）**必要但不充分**；
给出①**充分性诊断**与②**权重无关**的校正程序，使不能吃 `sample_weight` 的模型也能产出对目标人群有效的概率。

| 项 | 内容 |
|---|---|
| **被推翻条件** | 若"设计匹配的加权"能把校准截距拉回 ≈0 且均值 p ≈ π，则"不充分"不成立 |
| **结构性空缺理由** | 需要**同一数据在多种抽样设计下**的对照概率与校准——常规研究只有一种设计（别人做不了） |
| **已有证据** | ✅ 偏移量取对（−2.025，与公式 −2.02 吻合）后，均值 p 仍为 π 的 **0.4×**、校准截距 **+0.69**（`results/target_population_audit.txt`） |
| **待补** | B2（XGB 三处理）、B3（TabPFN 三处理，含等渗重校准）、B4（排序位移分解） |
| **决策后果** | 改变图上每一级的风险数值与其可用人群 |

**两类正交校正（N1 的理论骨架）**

| | 输出侧（单调） | 设计侧（拟合） |
|---|---|---|
| 手段 | 截距校正 / 等渗重校准 | 重要性加权 / 上下文按目标人群重采样 |
| 能修 | 概率尺度（Brier、可靠性、净收益） | **排序与边界**（AUC、选中集合） |
| 不能修 | **排序**（单调变换不变） | —（但需要权重或能重采样） |
| 领域现状 | 部分做了（2006 年 rare events LR） | 只在能吃权重的模型上做了 |
| **空白** | **充分性诊断**（何时不够） | **权重无关适配（ICL）** |

## 2. N2 —— "口径盲报告"的决策代价（N1 的一章）

**主张**：不声明目标人群的报道会同时污染**概率量级**与**排序**，并在**决策**上产生可量化后果。

| 项 | 内容 |
|---|---|
| **被推翻条件** | 若各口径的决策后果一致（选中面积、净收益排序不随口径变化），则主张不成立 |
| **结构性空缺理由** | 同 N1（需多口径对照档案） |
| **已有证据** | ✅ Spearman **0.669**；前 10% 面积选中集合重合 **54.4%**；分级一致率 **38.3%**；同一名义阈值 p_t=0.02 下选中面积 **16.4%~73.2%（4.5×）**、p_t=0.20 下 **0.2%~9.6%（44×）** |
| **待补** | B5：**完整净收益曲线** + **等面积**下的覆盖/漏检率（可比口径）+ **α ↔ p_t 对应表** |

## 3. N3 —— 空间支撑改变的是"概率对谁有效"（支撑轴；MIL 的正确化身）

**主张**：观测支撑（斜坡单元 vs 像元袋）改变的是**概率的语义与目标人群**，而不是"AUC 涨多少"。

**三臂设计**（判读三种结果都能写）：

| 臂 | 输入 | 含义 |
|---|---|---|
| A | 38 维聚合量（现主线） | 基准 |
| B | 像元袋 + 像元坐标 | 组成 + 空间排布 |
| C | 像元袋 + **袋内像元打乱** | 只有组成，无排布 |

**判读**：B>C>A → 排布有信息；B≈C>A → 只需像元分布；B≈C≈A → **聚合不是瓶颈**（负结果同样可写）。

| 项 | 内容 |
|---|---|
| **判据** | 主指标 = 消落带内子集 AUC；**Δ > MDE 0.0069** 且两分折同号 |
| **被推翻条件** | 支撑效应 < MDE → 改述为"聚合已足够" |
| **现状** | 脚本就绪（`v2_build_unit_grid` / `v2_build_unit_bags` / `v2_model_mil`）；本地 GPU 可达；**预处理需 rasterio（本机被系统策略拦，需服务器或自写解码）** |
