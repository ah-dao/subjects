**目标**：找到能**取代 XGBoost、并在同一口径下更准**的模型，且具备本领域当前没有的创新点、工作量可控。

**判定标准（缺一不算"取代"）**

| 量 | 结果 |
|---|---|
| 残差 Moran's I（y−p） | +0.0581（logit 残差 +0.2232） |
| 邻域残差→标签 AUC（仅排除同 3 km 块） | **0.5453** |

但"地图生产口径 +0.0067"可作为**出图后处理层**单列产出（§3.4）。

## 3. M1 库水位-高程神经算子（Reservoir Exposure Operator）｜1 周

### 3.1 物理形式与出发点

现有特征只用了一个标量泛函：

```
inundation_fraction_i = E_t[ F_i(L(t)) ]      L(t)=逐日库水位, F_i=单元内高程的累积分布
```

`wet_dry_cycles / max_drawdown_rate / ant_*` 都是它的粗糙补丁。**时间顺序、频率结构、骤降速率谱
全部被丢掉**，而消落带内的判别力瓶颈（AUC≈0.71）正是在这个子集上。

### 3.2 算子定义（可学习版本）

对 21 年逐日水位序列 L(t) 取 K 组时间滤波器/编码器 φ_k（可学习），与单元高程 CDF F_i 做交互：

```
z_ik = E_t[ φ_k( L(t), ΔL(t) ) · F_i( L(t) ) ]        k = 1..K   →  K 维"库水作用响应谱"
外加：F_i 的高阶矩（分位差/极差/坡度-高程相关）与 z 的交互
```

- **数据已全在本地**：`features/v2/sources/daily_station_levels.csv`（4 站逐日 2003-2021）、
  `features/v2/groups/elevation_quantiles.csv`（n_px + p05…p95 + min/max）；**无需任何新数据**。
- **两种实现路径**（建议先 a 后 b）：
  - **(a) 特征化路线（2 天）**：用一组固定基函数（不同时间尺度的滑动均值/差分、月序相位、极值统计）
    生成 20-40 维显式算子特征 → 直接进 XGBoost，用**现成的置换零分布协议**判定。风险最低，可立刻给答案。
  - **(b) 端到端路线（1 周）**：1D-CNN / 小 Transformer 编码 L(t) → 与 F_i 的嵌入做双线性交互 → 输出标量/向量；
    用残差式融合（预测 XGBoost 的 logit 残差）保证不劣于基线。

### 3.3 验收与落点

- 验收：消落带内子集（6,709 单元/623 正样本）AUC 必须**超过该子集的 MDE**；全库 soft02 不许变差。
- 新脚本：`tills/v2_extract_water_operator.py`（a 路线特征）+ `tills/v2_model_waterop.py`（b 路线模型）
- 产物：`features/v2/groups/water_operator.csv`、`results/v2_model_waterop_*.txt`
- 风险对策：若 a 路线无增量 → 说明现特征已覆盖时间结构，**如实记录后不再投 b 路线**。

## 4. M2 MIL 单元袋多尺度注意力网络（MIL-UAN）｜2-3 周

### 4.1 出发点（第 8 节原话）

> "机制发生在具体岸坡面上（某处 2-3 个像元的软岩恰在水线附近），而单元级面积占比把'在哪里'平均掉了。"

**像元级信息是 XGBoost 结构上无法表达的**——这是唯一能突破 0.71 天花板的输入。

### 4.2 规模已核实（可行）

| 量 | 值 |
|---|---|
| 单元像元数（30 m） | 中位 **307**、90 分位 503、最大 15,795 |
| 全库像元总量 | **841 万**（≈6,248 km² / 900 m²） |
| 每单元每步采 64 token | 每 epoch 仅 166 万 token（小 ViT 量级，CPU 也能跑） |

### 4.3 架构

```
单元 i = bag{ x_p }_p∈i        x_p = 30 m 地形栈（高程/坡度/坡向/TRI/曲率）+（可选）S2 波段
  ├─ 逐像元 MLP → 2 层自注意力 / 门控注意力池化 → 单元级"关键带"表示 h_i^mil（含注意力权重 a_p）
  ├─ 表格塔：XGBoost 38 维 → logit_i^xgb（冻结）
  └─ 残差式融合：logit_i = logit_i^xgb + g(h_i^mil, 表格特征)      ← 保证不劣于基线
```

- **残差式融合是硬性设计**：既保证不劣于 XGBoost，又让消融干净（Δ 必须来自 MIL 分支）。
- **创新点**：① 学习式**关键带注意力图**（像素级解释，比 SHAP 更适合空间机理叙述）；
  ② 消落带特有的"水线附近像元"可被注意力自动定位，并与 M1 的算子互相印证；
  ③ 单元=像元袋的多示例学习在滑坡易发性里罕见。
- **待补前置**：需生成 `unit_id` 栅格（用 `data/slope_units/slope_units_final.shp` + rasterio，一次性，分钟级）；
  S2 影像若要用，需走 GEE 导出（决定是否上 GPU 的关键）。

### 4.4 验收与风险

- 训练用 matched5 口径（3.2k）降过拟合，出图用 soft02 口径；报告**两者都要**。
- 必须过 **M8 组内判别力检验**（证明不是又一个位置代理；这是我们从顺向坡身上学到的教训）。
- 风险：661 正样本 → bag 子采样 + 强正则 + 早停 + 与 XGBoost 残差式融合兜底。

## 5. M3 TabPFN 基础模型线（T1–T4）

### 5.1 为什么它值得做（而不是放弃）

1. 它是本项目**唯一曾经胜过 XGBoost 的模型族**；v2 上的对比**尚属空白**。
2. 它的差别是**归纳偏置与推断方式**，不是容量——第 7 轮的"加容量无效"不能推论到"换模型族无效"。
3. 它天然适配我们的**小样本战场**：matched-pool（3.2k）与消落带内（6.7k）都在其上下文能力范围内。
4. 它的两个特性正好对上我们的**方法学痛点**：`fit()` 无 `sample_weight`（→ 逼出上下文构造方法学）、
   输出校准良好（→ 可做共形预测与风险受控出图）。

### 5.2 入场实验（**必须先做，否则后面赢了也说不清**）

**设计：2 模型 × 2 人群 的配对实验**

| 格子 | 模型 | 人群（训练上下文） |
|---|---|---|
| ① | XGBoost | soft 等效人群（近区权重 1 / 远区 λ 子采样） |
| ② | TabPFN | 同一个 soft 等效人群（上下文构造=按 λ 子采样远区，正样本全保留） |
| ③ | XGBoost | matched-pool（病例-对照匹配 k=5） |
| ④ | TabPFN | 同一个 matched-pool |

- **必须在同格内人群完全相同**；两模型用同一折、同一种子配对比较。
- **不靠"加样本量"提检验力**（matched5 的 MDE 是 0.0065，赢 0.005 也检不出），
  而是**把重复次数提到 10-20 次**（TabPFN 的上下文子采样天然提供随机性），用重复把零分布 SD 压下来。
- 主战场 = **matched-pool（3.2k，甜区）**；soft 等效口径（λ 子采样到 12k）作复核。
- 代码前置（`baseline_tabpfn.py`）：**补 `--features-csv` / `--features`**（现硬编码 v1 表）、
  **补 `matched` 分支**（复用 `src/dataset.matched_negatives` 与 `baseline_xgb.py` 的匹配诊断，输出 SMD/混杂 AUC）。

### 5.3 四条创新路线

| 编号 | 创新点表述 | 为什么成立 | 工作量 | 验收 |
|---|---|---|---|---|
| **T1** | **上下文构造 ↔ 目标人群的等价性**：ICL 模型无 `sample_weight`，软负采样口径**物理上无法直接移植**；提出上下文构造实现人群控制，并用 SMD/混杂 AUC 证明等价 | runner 已实现"远区按 λ 子采样"，但**从未证明等价性**——这是方法学缺口 | 3-5 天 | 同人群 SMD<0.1、混杂 AUC≈0.5；且与加权版 AUC 配对无显著差 |
| **T2** | **模型族 × 负采样口径交叉实验**：GBDT 对口径高度敏感（0.9095 → 0.8146，MDE 差 2-3 倍），ICL 是否更稳健 | GBDT 那两格已测，ICL 那两格为空；填上即新发现，并解释 v1 被混淆的"胜出" | 5-7 天 | 2×3 因子表（2 模型 × 3 口径）配对比较 + z 值 |
| **T3** | **用低方差模型压低检出限**：表格基础模型 OOF 方差更小 → 检出 GBDT 检不出的弱效应（地质 +0.001~0.004） | 直接回答上一阶段头号悬案（MDE > 效应量） | 1 周 | 复用第 10 轮 22 臂网格只换模型；比较零分布 SD、gap、z |
| **T4** | **风险受控的易发性图（共形预测）**：为分级给出覆盖率保证（"极高易发区确实含 ≥90% 滑坡"） | TabPFN 后验校准良好；领域内罕见；与出图主线直接咬合 | ~1 周 | 经验覆盖率校验 + 与现有等频分级的面积-召回对比 |

**建议顺序**：T1（必须先踩的坑）→ T3（把悬案变卖点）→ T2 → T4。

### 5.4 与 M1/M2 的关系

M3 不改变信息集 → 天花板与 XGBoost 同源；M1/M2 改变信息集 → 天花板更高。
最终形态：**M3 主模型 + M1/M2 新信息模块 + 残差式融合**，构成"表格基础模型 + 空间/像元基础模型"的模型线叙事。

## 6. 统一实验协议（M1/M2/M3 共用）

1. 口径：`soft02`（λ=0.2 软负采样，缓冲 4 km）与 `matched5`（病例-对照 k=5 + 先验校正），**两套都报**。
2. 分折：`admin` 与 `spatial_kmeans`（5 折），种子 42/43/44（方差大的模型提到 10-20 次重复）。
3. 显著性：同列数**整块行置换零分布** → gap 与 z；Δ 必须**超过该口径 MDE**且两分折同号。
4. 空间诚实性：**禁用邻域已知标签平滑**进泛化评估；地图后处理口径单列（§3.4 与 §7）。
5. 诊断：matched 口径必报 SMD 与混杂 AUC；所有新特征必过 **M8 组内判别力**（防位置代理）。
6. 复现：每次运行 JSON 落 `results/runs/<实验名>/`（沿用 r9/r10 的"新文件集合差分"写法）；
   结论写 `results/<实验名>.txt` + 在 docs 增补一节。

### 11.2 M1(a) 库水位-高程算子：已算出并完成判定（**未通过**）

**做法**（`tills/v2_extract_water_operator.py`，1 秒完成，无需新数据）

把现有标量泛函 `inundation_fraction_i = E_t[F_i(L(t))]` 推广为 K 个时间滤波器的耦合：

```
opw_k(i) = (1/n_i) Σ_{p∈i} Φ_k(e_p),      Φ_k(e) = (1/T) Σ_t φ_k(t)·1{L(t) > e}
opc_k(i) = opw_k(i) / opw_1(i)            （条件化：水下时的强迫强度，去掉"暴露量"成分）
opq_p(i)  = Φ_k(e_p)  [p = p10/p50/p90]   （族 C：把响应锚定到单元自己的高程分位，
                                           并给出单元内强迫梯度 opq_grad_k）
```

滤波器 φ_k ∈ {淹没时长、日均降幅、日均升幅、7 日降幅、30 日降幅、7 日骤降≥1.5m 频率、
日波动 |dL|、消落期(6-9月)占比、蓄水期(11-3月)占比、消落期降幅}，共 10 个；
用 **逐像元高程**（`elev_pairs.npz`，841 万像元）精确积分，不用分位近似。

**产物（全部新增，未触碰主线）**：`features/v2/groups/water_operator.csv`（25,939 × 31 列，0 NaN）、
`results/water_operator_report.txt`、`tills/v2_extract_water_operator.py`、`tills/v2_eval_water_operator.py`、
`results/water_operator_eval.txt|json`。

**机器校验**：`opw_1`（即"淹没分数"）与现有 `inundation_fraction` **r = 0.99999、平均绝对差 0.00035**
→ 算子实现与原特征口径一致。过程中修掉一个真 bug：低于水位下限的像元曾用"按高程箱平均"而非
"φ 的时间均值"，导致 468 个单元（无 DEM 覆盖）出现 NaN 与 ~0.29 的系统偏差。

**判定实验**（`tills/v2_eval_water_operator.py`，基准 = 现行 38 维主线**只读**；
soft02 口径、spatial_kmeans 5 折 × 3 种子；零对照 = 同列数整块行置换）

| 特征臂 | 列数 | 全库 AUC | 零均值 | gap | z | **消落带内 AUC** | 消带内 Δ | 配对 Δ vs base38 | 判定 |
|---|---|---|---|---|---|---|---|---|---|
| base38 | 38 | **0.9047** | — | — | — | **0.7162** | — | — | 基准 |
| A `opw_*` | +10 | 0.9046 | 0.9043 | +0.0003 | +0.32 | 0.7160 | +0.0007 | −0.0001 (p=0.85) | ❌ |
| B `opc_*` | +9 | 0.9023 | 0.9039 | −0.0016 | −1.00 | 0.7096 | −0.0047 | **−0.0024** (p=0.06) | ❌（反而变差） |
| C `opq_*` | +12 | 0.9056 | 0.9049 | +0.0006 | +2.19 | **0.7187** | +0.0011 | +0.0009 (p=0.24) | ❌（低于 MDE） |

**三条读数**

1. **A 族 ≈ 0**：与现有特征高度共线（|Spearman r| 达 0.99~1.00，见 report 校验 2）——
   暴露加权响应本质上就是"淹没时长"的再表达，**没有新信息**。
2. **B 族反而有害（−0.0024）**：条件化（除以暴露量）在暴露很小时比值不稳定，且丢掉了幅度信息。
   这是一个**有价值的负面结论**：把"强迫强度"从"暴露量"里剥离，在本数据上不成立。
3. **C 族方向为正且最独立**（与淹没分数 |r| ≈ 0.54，`opq_p50_2` 最低），
   全库 +0.0009、消落带内 +0.0011、z=+2.19（出零分布）——但**低于预设 MDE 0.0032**。
   ⚠ 注意：本脚本的 z 用"3 种子均值 vs 零对照 3 种子均值"计算，样本太少、SD 偏小，
   **不能与第 10 轮的 z 直接比**；可解读的是配对 Δ 与 MDE 的关系。

**结论与下一步**：按 §3.3 的预案——**a 路线未通过，不投入 b 路线（端到端时序模型）**。
理由：唯一有新信息成分的族 C 的增量（+0.0009~+0.0011）仍低于检出限，与地质 4 维的处境相同；
把工程量投到它上面的性价比不成立。**模型线重心回到 M3（TabPFN 入场实验，等服务器结果）与
M2（MIL 像元袋：唯一能改变"信息集"的方向）**。
C 族的 12 列已留在 `water_operator.csv` 中备用（若将来样本量扩大、MDE 下降，可低成本重测）。

### 11.3 算子的**有效性验证套件**（`tills/v2_validate_water_operator.py`）

**为什么不能只用 AUC 判**：§11.2 那把尺子（ΔAUC vs 置换零分布）在 661 正样本下 MDE=0.0032，
任何 ~0.001 的真实效应都检不出；而且算子列与现有特征高度共线，"加成"本来就不是它该赢的地方。
判断一个**物理算子**是否有效，要分层取证——V1 实现、V2 时序、V3 条件关联、V4 替代性、V5 运营指标。

| 层 | 检验 | 结果 | 判定 |
|---|---|---|---|
| **V1 构造效度** | `opw_1` 能否复现现有 `inundation_fraction` | r = **0.99999**，平均绝对差 0.00035 | ✅ 通过（实现无误） |
| **V2 触发时序一致性** | **时间分层自身对照 case-crossover**：658 个事件，前兆窗口 [D−30, D−1] 的 φ_k vs ①同日历窗口全年代 ②同为±2 年 ③同年其他窗口 | ① 降幅类滤波器**显著更低**（opw_6 −0.107、opw_2 −0.055）；② 控制时代趋势后收缩到 −0.021/−0.015；**0/8 个滤波器显著升高** | ❌ **不通过**（见下"重要修正"） |
| **V3 条件关联** | 消落带内（7,747 单元/623 正样本）按算子分位切分，控制 高程20m×坡度5°×淹没0.1（MH OR）+ 3 km 空间块 bootstrap | 4/7 列 CI 不含 1，但**符号不一致**：`opc_2` 0.755（保护）、`opc_5` 1.381（风险）、`opq_grad_2` 1.239（不显著） | ⚠️ 视为多重检验噪声，不构成一致机理 |
| **V3b 站内变异分解** | 每个水相关特征的变异有多少在"站点之间" | **`max_drawdown_rate` = 100.0% 站间 → 站点常数**（站内零变异）；`inundation_fraction` 0.12%、`opw_2` 1.8%、`opq_*` ≈1%、`opc_2` 11.5% → 均以站内变异为主 | ✅ **算子的独有优势**：能刻画站内差异，标量不能 |
| **V4 替代性（充分性）** | 删掉 5 个手搓水位标量、换成算子 C 族（45 列） | 全库 AUC **−0.0061**（0.9047→0.8986） | ❌ 不能替代：标量里含算子没有的信息 |
| **V5 运营指标** | 前 10% 面积召回（消落带内） | opq_plus **+0.0011**（可忽略） | ❌ |
| — | **子集自己的 MDE** | 消落带内零分布 SD 0.0035 → **子集 MDE 0.0069**（比全库 0.0028 更大！） | 提醒：子集不该沿用全库阈值 |

**重要修正（V2 揭穿了我第一版的假象）**
第一版只做了"事件窗口 vs 同年历窗口全年代"的对照，得到"滑坡前兆期降幅**更低**"（opw_6 −0.107）这种反直觉结论。
补了两个控制后真相清楚了：**事件年份高度集中在 2003–2009（658 个事件里 568 个）**，
而 2010 年后库水位运行规则才进入完整 145–175 m 消落（降幅更大）——所以"事件期降幅更低"是
**运行规则的时代趋势**假象，不是触发效应。控制时代趋势（±2 年对照）后效应收缩到 −0.02~−0.01，
且 0/8 显著。**结论：在这份编目上，"库水位骤降触发滑坡"这一时序假设无法证实**——
这与主线的既有发现一致（`ant_*` 事件窗口特征增益极小、位置/淹没主导）。

**算子有效性的总判定**：**物理上更规范、表达上更细（唯一能刻画站内水位强迫的水位特征），
但在这份标签 + 661 正样本下无法证明其"有效性"**：
时序触发关系不成立（V2）、预测增量低于检出限（§11.2 / V5）、也无法替代现有标量（V4）。
→ 维持 §11.2 的处置：**算子列留在 `water_operator.csv` 备用，不进主线，不投 M1(b)**。

**副产品（值得写进论文的两条）**：
1. **`max_drawdown_rate` 是站点常数**（站内零变异）——它只能当区域代理，不能解释站内差异；
   这解释了为什么"手搓水位标量"在控制位置后贡献有限。
2. **消落带内子集的 MDE（0.0069）比全库（0.0028）更大**——子集内正样本少、AUC 波动大，
   所以"在消落带内评判新模型"反而更难赢；若把子集作为主战场（§9 待确认第 5 条），
   必须同时扩样本或提高重复次数。

### 11.4 决策：M2 与 M3 的关系 —— **M3 先跑（半天，作为决策闸门），M2 作为主投入**

M1 已被否决（§11.2/§11.3）。剩下两条路不是二选一，而是"**先跑便宜的闸门，再投唯一的长期杠杆**"：

| | M3 TabPFN | M2 MIL 像元袋 |
|---|---|---|
| 现状 | **已就绪**（runner v2 化 + 离线权重 + 服务器包 109 MB） | 尚未开工（需 unit_id 栅格 + bag 采样器 + 模型） |
| 机时 | 入场实验约 2-3 小时 GPU | 2-3 周（含调参与验收） |
| 改变什么 | **不改变信息集**（还是 38 列）→ 天花板不变，只能更接近它、或把方差压小 | **改变信息集**（单元内像元）→ 天花板提高 |
| 不能做什么 | 不可能显著超过"位置层已达 99.4%"的天花板 | 仍有 661 正样本的过拟合风险 |
| 一定能产出什么 | T2（ICL vs GBDT 对负采样口径的稳健性）、T3（更低检出限）、T4（共形预测风险受控出图） | 像素级"关键带"注意力图（新解释产品）+ 唯一可能突破消落带内 0.71 的方向 |

**为什么 M3 先跑**：
1. 它已经 90% 就绪，成本只有半天；而它要回答的问题**现在悬着**——v1 那次 TabPFN 胜出已被整篇作废，
   v2 上从未测过。
2. **它的结果直接决定 M2 的接法**：若 TabPFN 胜出，M2 的像元分支应当与 TabPFN 融合（而不是 XGBoost）；
   若打平/输，M2 继续以 XGBoost 作表格塔。先跑 M3 = 先锁定 M2 的架构。
3. T3（若 TabPFN 的 OOF 方差更小）会成为**评判 M2 的更好仪器**——M2 的像元信息增益很可能也是弱效应，
   用低方差模型才判得动。

**判定与分支**：
