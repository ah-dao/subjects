# 滑坡易发性预测优化 —— 8 周执行计划

> 起点：2026-07-16 | 终点：2026-09-10
> 目标：30m 全分辨率逐像素易发性预测，独立看懂并优化项目

---

## 项目全景图

```
┌─────────────────────────────────────────────────────────────────┐
│                    滑坡易发性预测系统                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  数据层                                                          │
│  ├─ GEE 导出 5 通道 GeoTIFF (elevation, slope, aspect, TRI,      │
│  │   curvature) + 第6波段标签                                     │
│  ├─ prepare_data.py: 切 256×256 patch → debug_data/              │
│  └─ load_geotiff.py: 读取 GeoTIFF + 地理元数据                    │
│                                                                 │
│  模型层                                                          │
│  ├─ src/layers.py: CNNBlock (Conv→BN→ReLU)                       │
│  ├─ src/cbam.py: 通道+空间注意力                                  │
│  ├─ src/transformer.py: 空间位置编码 + Transformer                │
│  ├─ src/spp.py: 空间金字塔池化（多尺度）                           │
│  └─ src/model_segmentation.py:                                   │
│       ├─ LandslideProbabilityModel (当前: patch→1个概率)          │
│       └─ LandslideSegmentationModel (目标: patch→256×256概率)     │
│                                                                 │
│  训练/推理层                                                     │
│  ├─ main.py: 训练入口                                            │
│  ├─ src/dataloader.py: 数据加载 + 全局归一化                      │
│  ├─ src/debug_config.py: 超参数配置                               │
│  ├─ predict.py: 滑窗预测 + 出图                                   │
│  └─ src/visualization.py: 5级易发性可视化                         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 风险预案

| 风险 | 概率 | 应对 |
|---|---|---|
| 滑坡数据源不明确，无法做 mask 标签 | 中 | 用现有 GeoTIFF 第 6 波段代替，或手动标注 20 个 patch |
| 分割模型训练后 AUC 反而更低 | 中 | 退回只用 patch 分类模型，跳过分割，直接做因子工程 |
| Colab 12GB 内存不够跑 8 通道 | 低 | 提前降采样或分块 |
| AutoDL 没抢到 3090 实例 | 低 | 用 T4 替代，batch_size 降到 4 |

---

## 核心原则

1. **一次只改一件事**：改了就跑验证，确认有效再改下一件。不要同时改模型架构 + 数据 + 超参数。
2. **每个断点不通过就停下来修**：不要带病进入下一阶段。宁可慢一周，也不要推倒重来。
3. **实验记录**：每次实验记录「改了什么 / 训练参数 / 结果 / 结论」，用 Markdown 或 Excel 都行。
