# 主线升级后的消融与因子分析证据

当前屏障区主线为84维、空间五折、8成员、1:3子采样、seed42。已有原2成员4000样本的V3实验保持原始身份，不因采用新配置而作废，也不改成新模型的实验。

|证据|报告用途|不能据此声称|
|---|---|---|
|V3原配置40/48/84维对照|原配置下坡内信息与表征方式的对照|新1:3模型也有同样幅度的特征增益|
|V3原配置PFI、ALE|原模型的信息依赖与响应分析，注明配置|新8成员1:3模型的精确贡献排序或因果效应|
|同定义、同人口的FR/IV|滑坡在不同因子条件中的分布富集|新模型重要性或独立因果作用|
|同版本同分折的XGBoost消融|基线模型的补充证据|TabPFN主线的特征收益已被直接验证|
|V2/10月19日127维来源消融|前期探索或附录，标明旧口径|当前V3修正后84维方案的直接证据|

FR/IV虽不依赖分类器，但依赖统计人口、因子定义、分组与时间参照。不能把训练上下文统计当作全屏障区统计。原2成员canonical解释保留来源身份，不直接套用到新主线。

## 已核验的V3表征对照

来源：results/v3_received_controls_s42/comparison_metrics.csv。空间五折、seed42、完全相同4000上下文、2成员、不启用概率平衡：

|输入|AUC|AP|C20|
|---|---:|---:|---:|
|table40：38维因子+2维可用性|0.897932|0.178041|75.49%|
|means48：40维+8通道均值|0.897185|0.176933|75.64%|
|stats84：40维+44维统计|0.908904|0.178277|80.03%|

84维相对40维的AUC和C20提高，但AP仅提高约0.00024，不应写成所有指标均明显改善。48维结果也不支持“只加均值必然改善”。这些匹配的TabPFN对照比单独用XGBoost消融替代更直接。

## 最少补什么

优先补新主线下40维、48维各5个空间折，共10个新增拟合任务；84维复用已完成1:3结果。共享日期、冻结折、4000候选ID、相同8套成员子采样ID、种子和预处理规则，仅改变输入列。当前尚未新增这些实验的运行代码或宣称它们已完成。

若报告必须给最终主线的模型贡献，之后优先补预先定义的因子组置换，不必立即重做全部84维ALE。新解释需匹配8成员1:3预测及保存/重载或独立重拟合验证，不能只改旧canonical参数就复用旧模型。

若没有依据预先规定的规则删除变量并验证，章节建议称“评价因子构建、表征对照与作用分析”，不将按测试折选择方案写成独立因子筛选。比例选择用过第0折，最终五折结果也不等于全新的独立测试。

## 现阶段报告表述

“本研究构建多源单元因子及坡内统计特征，并在固定空间分折和训练样本条件下开展表征对照。原配置下，加入坡内分布统计后，AUC由0.8979提高至0.9089，前20%面积滑坡覆盖率由75.49%提高至80.03%，AP变化较小。因子信息量用于描述滑坡在不同环境条件中的富集，置换与响应分析用于说明原配置模型对相关信息的依赖。在保留上述特征体系的基础上，后续采用8成员、1:3子采样形成当前屏障区评价结果。”

在新配置匹配对照补齐前，保留“原配置下”的限定。不要把旧消融数值与新主线评分拼成同一次实验的递增过程。XGBoost作为前期基线探索，无需提升为新主线的直接证明。
