# 事件对齐特征表说明（k=2，推荐版）

## 1. 文件与构建口径

| 项目 | 内容 |
|------|------|
| 特征表 | `features/event_window_features_k2.csv` |
| 形状 | 25884 行 × 22 列（unit_id + 20 特征 + label） |
| 特征数 | 20 维 = 静态 14 + 事件前 K 窗口 6 |
| 样本 | 正样本 662（2.56%）/ 负样本 25222 |
| 缺失值 | 0 |
| 构建脚本 | `tills/build_event_window_features.py --k 2 --start-year 1997 --seed 42` |
| 年度矩阵 | `features/ndvi_unit_matrix.csv`、`rain_unit_matrix.csv`（1997–2021，25 年） |
| 基线性能 | XGBoost 5 折空间 CV：**AUC 0.7096 ± 0.0231**（`results/baseline_xgb_ew_feat_k2.json`） |

**关键口径（防泄漏）**：
- 参考年 T：正样本 = 研究期首次滑坡年份；负样本 = 从正样本年份分布频率匹配采样（seed=42，与单元无关）；
- K 窗口 = `[T−2, T−1]`，只使用事件前数据，杜绝未来信息；
- 长期基准 = `[1997, T−1]`（补全 GEE 数据后含 1997–1999）；
- 静态特征与时间无关，正负样本同口径。

## 2. 静态特征（14 维，时间无关）

### 2.1 静态地形（5 维，单元内栅格 zonal mean）

| 特征 | 计算方式 | 物理意义 |
|------|----------|----------|
| `elevation_mean` | 单元内高程均值（SRTM, m） | 高程带位置，决定与库水位涨落区间的关系；消落带滑坡多集中于特定高程带 |
| `slope_mean` | 单元内坡度均值（°） | 越陡下滑分力越大，经典易发性因子 |
| `aspect_mean` | 单元内坡向均值（0–360°） | 日照/干湿差异（循环变量，普通均值存在环绕误差的已知局限） |
| `TRI_mean` | 地形粗糙度指数均值 | 地表起伏程度、地形破碎度 |
| `curvature_mean` | 单元内曲率均值 | 凸坡应力集中 / 凹坡积水饱水 |

### 2.2 静态几何（3 维，UTM 投影计算）

| 特征 | 计算方式 | 物理意义 |
|------|----------|----------|
| `area` | 单元面积（m²） | 单元/坡体尺度；单变量 AUC 最高（0.631） |
| `compactness` | 4π·面积/周长² | 形状圆整度（1=圆，越小越狭长） |
| `shape_index` | 周长/(2√(π·面积)) | 形状复杂度，与地形破碎相关 |

### 2.3 淹没交互（6 维，高程 × 库水位，全研究期 2003–2021）

| 特征 | 计算方式 | 物理意义 |
|------|----------|----------|
| `inundation_months_avg` | 年均淹没月数（水位≥单元高程的天数/30.4） | 淹没浸泡时长 |
| `inundation_fraction` | 2003–2021 被淹没时间比例 | 淹没频率 |
| `inundation_episodes` | 淹没期次数（间隔≤5 天合并） | 干湿交替次数 |
| `max_inundation_depth` | max(水位−单元高程, 0)（m） | 历史最大淹没深度 |
| `mean_inundation_depth` | 淹没期间平均淹没深度（m） | 淹没强度 |
| `inundation_annual_std` | 年淹没月数的年际波动（月） | 淹没年际变率 |

## 3. 事件前 K 窗口特征（6 维，k=2，前缀 `k2_`）

口径：窗口 = `[T−2, T−1]`，T = 参考年（正样本首次滑坡年 / 负样本频率匹配伪事件年）。

| 特征 | 计算方式 | 物理意义 | 重要性(0.0906) / 单变量AUC |
|------|----------|----------|------------------------------|
| `k2_ndvi_mean` | 事件前 2 年 NDVI 年均值的平均 | 事件前植被状态水平；低 NDVI = 坡体裸露/植被退化 | XGB 最重要特征 0.0906 |
| `k2_ndvi_change` | 事件前 2 年 NDVI 均值 − 长期均值（[1997, T−1]） | 事件前近期植被相对长期的变化，**负值 = 近期退化** | 0.0511 |
| `k2_maxdaily_max` | 事件前 2 年"年最大日降雨"的最大值（mm） | 事件前极端降雨峰值 | 0.0484 |
| `k2_max30d_max` | 事件前 2 年"年最大 30 日累计降雨"的最大值（mm） | 事件前连续降雨饱水程度峰值 | 0.0578 |
| `k2_heavydays_sum` | 事件前 2 年暴雨日数（>50mm/日）之和 | 事件前极端降雨频率 | 0.0505 |
| `k2_cumulative_mean` | 事件前 2 年"年累计降雨"均值（mm） | 事件前湿润背景/降雨总量 | 单变量 AUC 0.537（k2 组最高） |

## 4. 基线性能与敏感性（供汇报引用）

| 实验 | AUC |
|------|-----|
| 原静态全窗口 22 维 | 0.6944 ± 0.0451 |
| 静态 + 事件前 k=2 窗口（**推荐**） | **0.7096 ± 0.0231** |
| k=1 / k=3 / k=4 / k=5 / k=6 | 0.6346 / 0.6966 / 0.7029 / 0.7033 / 0.7086 |

- k≥2 显著优于 k=1（单年窗口信息不足）；
- k=2 与 k=6 差异在噪声内（0.7096 vs 0.7086），选择 k=2 基于稳定性（std 0.023 最小）与模型简洁性；
- `k*_ndvi_mean` 在所有 k 下均为 XGBoost 最重要特征，`k*_cumulative_mean` 单变量 AUC 随 k 增大而上升（湿润背景是稳健因子）。

---

## 5. 泄漏检查摘要

- 负样本参考年 T 从正样本年份分布频率匹配采样（固定 seed，与单元无关）→ 窗口位置正负同分布；
- 所有时序特征只用 `[1997, T−1]` 数据 → 无未来信息；
- 静态特征时间无关，正负同口径；
- 特征与标签不同源（无复发类特征）。

---

## 6. 数据说明

- 1997–1999 数据由 GEE 补齐（Landsat 5 TM NDVI 90m + CHIRPS 降雨），已合并入年度矩阵；
- 1998 年 NDVI 有 495 个单元缺失（1.9%，其中正样本 11 个），窗口统计用 nanmean 跳过，不影响结果；
- 1997–1999 NDVI 均值（0.24–0.27）略低于 2000 后（0.28–0.30），属传感器/生长季差异，值域正常。
