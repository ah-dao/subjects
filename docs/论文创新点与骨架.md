## 0. 一页主张（给老师看的第一屏）

> **我们不再只问"哪个模型更强"，而是问"哪个结论可信"。**
> 本文提出两件方法：(1) **噪声分解的检出限协议（NDDL）**，用于判定因子集/模型比较的结论是否超出可分辨范围，
> 并在实验前预测"换模型是否有用"；(2) **机制分层的适用域检验**，把易发性图从"全域可用"改为
> **带适用域声明的管控图**。二者合起来交付一张**带漏检率保证、且写明适用边界**的消落带易发性图。

**为什么必须这样定位**：本项目的峰值增益是 TabPFN 相对 XGBoost 的 **+0.006 AUC**（真实、超 MDE、已排除人群混淆），
但它**不改变任何一句管理结论**。而项目中被证明能改写结论的东西，全部来自**判定口径与适用域**（见 §1）。
评审说"不要堆结构"是对的：本问题没有架构型创新的位置。

## 1. 创新点的层级

| 层级 | 创新点 | 一句话主张 | 为什么算"新方法"（而非流程/结构） | 现有证据 | 缺什么 |
|---|---|---|---|---|---|
| **主** | **NDDL：可分辨性协议 + 预算最优分配**（定位见 §9 文献查证） | 因子/模型比较必须先给出"最小可分辨效应"；把零分布方差拆成**模型侧（种子）**与**数据侧（置换）**，给出与统计量匹配的标准误、多重比较控制，并**解出固定算力下 S（种子）×K（置换）的最优配比** | ⚠️ **MDE 概念在遥感精度评估早有先例（Foody 2009）、"resolving power"亦已提出** → 本工作定位为**领域翻译＋集成**；**真增量是"实验预算最优分配公式"与"meta 审计"**（检索未见） | ✅ 第10轮 732 次运行的 MDE 被高估 **1.0~1.9 倍**；✅ 复现其口径；✅ sel4 修正后（20 置换）行政折 p=0.035、空间折 p=0.306 → 结论改述为"**检验力不足**"；✅ σ 比值 sel4=2.0~4.8×（换模型有用）、allgeo14=0.35~0.41×（无用） | 🔧 模拟研究（E1）；🔧 预算分配公式的推导与验证（已有 (3,5) 与 (3,20) 两组可验）；🔧 meta 审计 |
| **交付** | **机制分层适用域检验** | 易发性图的判别力由单一机制驱动，**图的适用域与机制域重合**；提出"先划机制域、再分层外部验证"的协议 | 把"外部验证"从"换一组点算 AUC"改为**机制域分层检验**，产出可写进管控文件的**适用域声明** | ✅ 消落带内 42 个**编目外**滑坡前10%命中 **54.8%**（样本内基准 54.7%）；✅ 消落带外：外部 39 个与编目自身 38 个**均 0.0%**；✅ 判别力 99.4% 来自 15 个水位-位置变量 | 🔧 带外样本仅 39 个（0 命中的 95% 上界≈9%）→ 补**分高程带的完整覆盖曲线**；🔧 带外机制需独立解释（不能只说"模型不适用"） |
| **交付** | **分区共形风险受控图** | 把易发性图升级为**带漏检率保证**的分区图（漏检率 ≤ α），并针对空间异质性提出**分区块校准** | 共形预测在滑坡易发性罕见；**空间分块校准 + 覆盖缺口诊断**是在既有方法上的实质扩展（全局交换性不成立时的补救） | ✅ 交叉共形 α=0.10 → 25.7% 面积、实测覆盖 88.4%（α=0.20 → 19.6%/78.7%）；✅ 校准良好（Brier 0.0233 = 可靠性 0.0002 − 分辨率 0.0023 + 不确定性 0.0252） | 🔧 量化**全局共形在分区块下的覆盖缺口**，并证明分块后闭合（半小时级，见 §4） |
| 探索 | MIL 像元袋注意力（M2） | 单元内像元级信息是否突破消落带内 0.71 天花板 | ⚠️ **gated attention 是 2018 年既有方法**，本身不算创新 | 🔧 未出结果 | 🔧 仅在消落带内子集增益 **> MDE 0.0069** 时才升格为贡献，否则写为"探索性尝试/阴性结果" |

**层级关系**：主创新（方法学）决定论文能否立住；两个交付级方法决定**你的图能不能被用**；MIL 是唯一的判决性探索实验。

## 5. 评审可能追问 & 备答

| 追问 | 备答 |
|---|---|
| **"新方法在哪？"** | NDDL 协议：零分布方差分解 + 匹配标准误 + σ 比值事前诊断；并给出模拟与实证证明常规做法会漏检（§4-E1） |
| "这不就是用现成统计量拼的吗？" | 统计工具是标准的，**新在协议与诊断量**（σ 比值可在做实验前判断"换模型是否有用"），且**实证纠正了领域内普遍做法**——这是方法学论文的常规形态 |
| "为什么不做新网络结构？" | 本项目判别力 99.4% 来自 15 个水位-位置变量，消落带内用尽全部特征仅到 0.7162 → 瓶颈是**信息集与标签量**，不是结构；换模型实测只值 +0.006，且不改管理结论 |
| "凭什么说常规做法错？" | 复现其口径（0.0009/0.0016/0.0029/0.0040）后指出：其零 SD 含种子间波动、未除以 √n，却用于卡"已平均 3 种子的 gap" → 门槛高估 1.0~1.9 倍 |
| "你的 p=0.035 算不算多重比较？" | **两种口径都报**：sel4 是**预先指定的主假设**（家族=1）→ p=0.035；若按第 10 轮"10 个臂一起测"的家族 → p_holm≈0.35。脚本输出里 family_m 已显式打印，避免误读 |
| "外部验证只有 133 个、还重叠 52 个？" | 明确写为"编目外"而非"独立"；分层后带内 42 个命中率与样本内持平（54.8% vs 54.7%），带外与编目自身一致为 0% |

| "图能用吗？" | 带适用域声明与漏检率保证：消落带内、α=0.10 时 25.7% 面积兜住 88.4% 滑坡 |

## 14. 如何找到"适用 + 够新 + 能占有"的 niche：可复用方法

> 五轮检索（40+ 组）的经验已经足够提炼成方法。核心教训一句话：
> **成熟应用领域里，novelty 不在"方法"里，而在"只有你的数据才能揭示的约束"里。**

### 14.1 三条判据（缺一条就不做）

| # | 判据 | 检验方法 |
|---|---|---|
| 1 | **结构性空缺** | 空缺必须有**结构性理由**（别人缺数据/缺设计），而不是"没人想到"。→ 反例：预算最优分配（无人据它做决定，故无人写）；正例：多口径校正充分性（需要多口径档案，别人没有） |
| 2 | **可证伪** | 能用一句话写出"什么结果会推翻它" |
| 3 | **可占有** | 能用"一段话 + 一张图"钉死，且别人**短期内复制不了**（因为缺你的数据） |

补两条加分项：**改变某个真实决定**；**能一句话答掉"这不就是 X 吗"**。

### 14.2 找 niche 的六步流程

| 步 | 动作 | 产出 |
|---|---|---|
| **1 换搜索对象** | 不要搜"方法 + 领域"，要搜**"主张 + 领域"**：领域正在下哪些结论、依据是什么 | 主张清单（→ `docs/主张台账.md`） |
| **2 找结构性空缺** | 对每条主张问："要检验它，需要什么数据？标准数据集有吗？" → **标准数据做不到的，就是结构性空缺** | 空缺清单 |
| **3 三条造 niche 的路径** | ①**资产驱动**：从独有数据出发问"它让什么主张成为可检验的"（不是"我能跑什么方法"）；②**矛盾驱动**：找领域内两个同时被相信却冲突的说法，用你的数据裁决；③**失败驱动**：把阴性结果变成**边界主张**（"X 在什么条件下不成立"） | 候选 niche |
| **4 过三判据 + 两加分项** | 见 §14.1 | 存活候选 |
| **5 写"主张"而非"方法"** | 一句话主张 + 一条被推翻条件 + 一项决策后果 | 定位句 |
| **6 占有** | 见 §14.3 | 时间戳与工件 |

### 14.3 怎么"占有"（这一步最容易被忽略）

| 动作 | 为什么有效 |
|---|---|
| **预注册**：把主张与判据写在跑实验之前（本项目已有 MDE 判据的习惯，把它形式化） | 事后挑口径会被质疑，预注册使结论不可争议 |
| **最小可发表单元（MVP）优先**：先用最少的证据（如 B0 的两张表）发出预印本 | 领域进口速度是"两年"，**时间戳比完美更重要** |
| **命名**：给现象或流程起一个可被引用的名字 | 有名字的现象/协议才容易被引用，也难被替换 |
| **发布可复用工件**：脚本、抽出的数据表、判据实现 | 成为"工具所有者"是一种占有（本项目已有 `tools/lit_fetch_check.py`、MDE 审计、B0 审计） |
| **台账化**：把主张、状态、证据、时间戳记在一个文件里 | 防止重复劳动，也方便导师/合作者对齐（→ `docs/主张台账.md`） |

### 14.4 用本法筛出的存活候选（按可行性排序）

| # | 主张 | 结构性空缺理由 | 你的依据 | 判据 | 决策后果 |
|---|---|---|---|---|---|
| **N1** | **抽样设计的"校正充分性"**：教科书式的 case-control 校正必要但**不充分**；给出充分性诊断 + **权重无关**的校正程序（供 ICL/表格基础模型使用） | 需要**同一数据在多种抽样设计下**的概率与校准对照——常规研究只有一种设计 | ✅ B0 已证：偏移取对后仍偏 2.5×、校准截距 +0.69；✅ 4 口径 × 2 分折档案 | 若设计匹配的加权能把校准截距拉回 ≈0 且均值 p≈π，则"不充分"被推翻 | 改变图上每一级的风险数值与其使用范围 |

| **N3** | **空间支撑轴**：观测支撑（斜坡单元 vs 像元袋）改变的是"概率对谁有效"，而非"AUC 多少" | 需要同一区域内两种支撑的同设计对照 + 调查级因子 | ⚠️ MIL 未跑；但设计已就绪（三臂含袋内打乱） | 支撑效应 < MDE 则主张改为"聚合已足够"（负结果也可写） | 决定制图单元选择 |
| **N4** | **编目时间不可靠**：库区易发性若用编目日期，结论可能由**调查强度**驱动 | 需要"编目日期 + 调查活动史"的对照 | ✅ 已实测：2000–2009 约 967 件 vs 2010–2021 仅 118 件 | 若能拿出证据说明 2010 年后调查仍在持续，则主张削弱 | 保护既有阴性结论不被误读 |

### 13.3 "case-control 校正 + 像元袋注意力 + TabPFN"三件套的判决

**作为"创新点清单"：没有竞争力。** 三项各自的状态：

| 项 | 状态 |
|---|---|
| case-control 校正 | ❌ 本领域 2006 年已有（rare events LR）；SDM/RS 均有成熟版 |
| 像元袋注意力（MIL） | ⚠️ gated attention 是 2018 年既有方法；像元 vs 斜坡单元已被研究（§11.1 Karnali）；本项目增益未验证 |
| TabPFN | ❌ 应用已发表（西北工业大学团队，西北地质 2026，§9.1） |

三样都是"用了什么方法"，**不是主张**；这正是评审说的"堆结构和堆流程"。

**但可以拧成一个主张**（把三者变成同一问题的三个轴）：

> **主张**：易发性模型的输出**只在声明了"目标人群 + 抽样设计 + 空间支撑"之后才有意义**；
> 现行做法（多口径混用、只做截距校正、单元级聚合）会同时污染**概率尺度**与**排序**，
> 且对不能使用样本权重的新一代模型（ICL/表格基础模型）缺少校正手段。
> 我们给出**设计—支撑—校正**三轴的形式化，量化各轴的后果，并给出**权重无关的校正程序**。

| 三件套 | 在新主张里的角色 | 判定方式 |
|---|---|---|
| 双口径（4 设计） | **设计轴**：量化排序位移与决策后果 | B0 已完成：54.4% 重合、38.3% 分级一致、4.5~44× 面积差 |
| case-control 校正 | **校正轴**：证明"标准校正不足" + 给出 ICL 的权重无关适配 | B2/B3 |
| 像元袋注意力 | **支撑轴**：空间支撑改变的是"概率对谁有效"，**不是**"涨多少 AUC" | 三臂设计（含袋内打乱），无论正负都能写 |

⚠ 诚实提醒：这样定位后，**创新点仍是"评估/有效性"性质**（不是新模型），但它是**模型侧的学习问题**（学习算法 × 抽样设计 × 空间支撑），
且第③块（权重无关校正）是可写成算法的**真方法**。

### 12.4 推荐：**准实验因果识别 + 风险集生存估计**（模型侧主线候选）

**主张**：库区滑坡易发性长期被当作"静态空间问题"，但其发生**由水库调度规程驱动**。
三峡调度规程本身经历多次变更（蓄水阶段推进、汛限与消落期规则变化），构成**准自然实验**。
把规程变更作为**外生冲击**，用**风险集（case-cohort）离散时间风险模型 / 因果森林**估计"消落暴露"对滑坡风险的**因果效应**，
并产出**随调度情景变化的危险率图**。

| 约束 | 如何满足 |
|---|---|
| 必须是**模型侧** | 交付**估计量**（风险率/因果效应），核心是生存模型与识别策略 |
| 不能是**堆结构** | 换的是**标签类型与识别假设**（time-to-event + 外生冲击），不是加一层网络 |
| 必须**可证伪** | ①规程变更前后消落带内风险率出现**断点**；②带外单元**不出现**（安慰剂）；③平行趋势检验 |
| 必须用**独有资产** | 逐日水位 + 带日期编目 + 规程知识 |

**设计草图**：①单元×月面板，用**风险集抽样**（每个事件时点从风险集抽对照）避免全量面板并顺带解决负样本口径；
②以规程变更为断点做 DiD / 事件研究，含平行趋势与安慰剂（带外单元、伪事件日期）；③离散时间风险模型（时变暴露：涨落速率、消落相位、前期淹没）+ 因果森林看异质性；④产出因果效应（为什么易发）+ 情景化危险率图 + 适用域声明。

**风险与应对**

| 风险 | 应对 |
|---|---|
| 事件数少（661，分到多个规程期后更少） | **先做功效核算**；若分期间效应低于可分辨水平，退化为"带内/带外对比 + 事件研究描述" |
| 降雨等共同冲击混杂 | 降雨入时变协变量 + 带外安慰剂；论证规程变更外生于降雨 |
| **编目检测偏差随时间变化**（本设计最大威胁） | 做**报告强度时间趋势检验**（逐年事件数 vs 遥感/调查可用性）；不成立则改用带内/带外对比 |
| 与"动态易发性"文献的关系 | 明确区分：他们更新**输入**，我们估计**因果效应 + 风险率** |

- **2000–2009 约 967 个；2010–2021 仅 118 个**（且 2000–2002 共 235 个落在逐日水位数据范围之外）。
- 这种断崖式下降**更像调查/填报活动的结束**，而不是滑坡真的在 2010 年后停止。该表出自**985 点调查表**，其"滑坡时间"很可能记录的是**填报/调查时间**。
- ⇒ **暴露（库水位调度规程）与调查强度完全混杂** → §12.4 的准实验/生存设计**在本数据上不可识别**，功效检查也不通过（175 m 正常运行期只有 118 个事件）。
- ★ **附带的重要收获**：这**重新解释了 M1 的阴性结果**——"V2 时序触发 0/8 显著"很可能**不是**"库水位不触发滑坡"，而是**日期本身由调查强度驱动**。这条既保护我们不下错结论，本身也值得写进讨论/局限（库区易发性的**编目时间可靠性**问题）。

### 12.7 四轮筛查总账：模型侧"新方法"窗口基本关闭

| 模型侧方向 | 判决 |
|---|---|
| PU 学习、贝叶斯/证据式不确定性、动态/时空易发性、域适应/迁移、物理知情 ML、空间增强 TabPFN、标签/采样表示（多边形 vs 质心） | ❌ 已占（8 个） |
| 生存/风险率（time-to-event） | ⚠️ 未被占，但**本数据不可识别**（§12.6） |
| 目标人群有效学习（case-control 先验校正／重要性加权 → 概率对**部署人群**有效） | 🟢 **检索未见 LSM 应用**（命中全在生物统计），但属教科书构件 → **薄但可辩护**；且与"不能吃样本权重"的 TabPFN/ICL 结合是一个适配点 |
| 因果识别（准实验/DiD） | 🟡 伞已占，且本数据不可行 |

**结论**：经 4 轮、20+ 组检索，**未能在模型侧找到一个干净且可行的"新方法"槽位**。继续猎取的期望回报已明显降低；
理性的分配是**把模型侧定位为"严谨的应用 + 一个薄增量"，把创新点放在已验证为空白的层（决策分析式评估，§11.3）**。

### 11.3 新的主推候选：**决策分析式易发性评估（net benefit + 风险控制 + 人群口径）**

**主张**：易发性图的最终用途是**决策**，而领域标准指标 AUC 是**阈值无关且与人群患病率无关**的，
因此**原理上无法回答"这张图值不值得用"**。我们把医学预测模型领域成熟 20 年的**决策曲线分析/净收益**
引入易发性制图，并与**共形风险控制**、**目标人群口径**整合，给出"图在什么决策阈值下、对哪个人群、才优于
'全部设防/全部不管'"的定量答案。

**为什么这次不是假缺口**（三条一起看）：
1. **有人据此做决定**：管控部门确实在"保护/监测某单元 vs 承担滑坡损失"之间做权衡；
2. **现有依据不可靠**：AUC 不含代价比，也不含人群患病率——同一张图在不同口径下的 AUC 差 0.09，但**净收益差异更大且方向可能相反**；
3. **空白已被两轮检索确认**：DCA 在 LSM 检索不到。

**与已有资产的三处咬合（这是它强的真正原因）**：

| 我们已有 | 与 net benefit 的关系 |
|---|---|
| 两套口径（soft / matched）AUC 0.82~0.91 | **AUC 与患病率无关，net benefit 与患病率强相关** → 口径问题从"指标争议"升级为"决策后果"（同一张图对谁能用不一样） |
| 交叉共形（漏检率 ≤ α，25.7% 面积 / 88.4%） | 共形给的是**漏检率**；DCA 给的是**代价比**——两者是同一决策问题的两个视角（α ↔ 阈值概率 p_t），可合并成一套"风险受控 + 净收益"的交付口径 |
| 适用域（消落带内 54.8% / 带外 0.0%） | 带外捕获率为 0 → 在 DCA 里等价于**"带外的净收益 ≤ 全部不管"** → 适用域从统计陈述变成**操作性规则** |

**需要做的实验（都可本地/CPU 完成）**：
1. 对 4 个口径 × 2 分折画 net benefit 曲线（含 treat-all / treat-none 基线），标出"图开始无用"的阈值；
2. 分消落带内/外分别画 → 检验"带外曲线是否落在 treat-none 之下"；
3. 与共形分级叠加：α 与 p_t 的对应表（一张表把"允许漏检率"翻译成"代价比"）；
4. 敏感性分析：代价比在合理区间内变动时，结论是否翻转。

**风险与反驳**：审稿人会问"代价比从哪来"——回答正是 DCA 的设计初衷：**报告整条曲线**，不绑定单一比值；
另可锚定一个可比区间（一个监测点成本 vs 一次滑坡损失）。**诚实定位**：这是**移植 + 扩展**（+口径显式化 + 共形整合），
需明确引用 Vickers & Elkin 2006，不是发明新统计量。

### 10.3 那创新点应该往哪去：三条现实路径

**路径 A（推荐主路）：把贡献放在"系统"而不是"方法"。**
我们手里别人不易有的东西：**受工程调度控制的库区 + 逐日水位（20 年）+ 661 个带日期的滑坡 + 手工数字化地层 + 985 点调查表 + 133 个半独立外部清单**。
可回答**只有我们这组数据能回答**的问题，例如：

1. 库水位调度节律（不是"距河距离"这种静态代理）与滑坡事件时序的关系，在**控制了位置与地形**之后还剩多少？
2. 同一张图在**不同调度情景**（正常蓄水位/汛限/消落期）下的风险排序如何变化 → 产出**情景化图族**而非单张图；
3. 手工地层真值 vs 全球粗岩性产品，能否解释"岩性在易发性里没用"这一常见结论（可能是**数据粗**造成的假象）。

**路径 B（若仍要方法学名义）：窄口径的"报告规范"。** 若最近 4 篇（§10.1 前四条）都**没有**给出可分辨性判据，则"**在易发性因子/模型比较中报告可分辨性**"仍可作为一个**小的方法学贡献**——但必须引用 KIGAM/Rudraprayag/Eng Geol 三篇并明确差异，且不能当作论文主卖点。

**路径 C（务实）：接受增量，把力气放在"完整、严谨、可交付"上。** 本领域绝大多数论文都是**增量式整合**；"新方法"的门槛主要由 CS 背景团队占据。一篇**数据独特、审计透明、结论有边界、图能落地**的库区研究，投 Landslides / NHESS / Engineering Geology / CATENA 是正常路径。

### 9.3 修正后的主创新：翻译 ＋ 一个真增量

**真增量（检索未见）＝ 实验预算的最优分配。** 固定算力下，臂均值估计的方差为

    Var = σ²_种子/S + σ²_置换/K + σ²_残差/(S·K)        （S=种子数，K=置换数，约束 S·K ≤ 预算）

由此可解出最优配比：**按噪声分量比例分配**（σ_种子 大就多跑种子、σ_置换 大就多跑置换），
产出如"给定 20 GPU·h，应跑 3 种子 × 20 置换，而非 10 种子 × 6"这类**可执行、可省钱**的结论。
最优分配是经典统计思想，但**用于易发性消融的实验预算**未见先例，且**可用已有数据直接验证**
（sel4 同时有 (S=3,K=5) 与 (S=3,K=20) 两组）。

**meta 审计（检索未见，可作第一张图）**：抽查已发表 LSM 论文的 ΔAUC/因子增益，
统计多少**低于其自身设计隐含的检出限**、多少**根本没报方差信息**——
把"这个领域在系统性报告无法判断的比较"变成可引用的数字。

因此修正后的主张：

> **"我们不提出新的统计量，而是给出把可分辨性接入易发性评估的协议与实验预算的最优分配公式；
> 并用 732 次运行的实证档案与一项 meta 审计，证明现行报告方式在多大规模上不可分辨。"**
