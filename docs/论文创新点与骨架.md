# 论文创新点、骨架与图表清单

> 用途：与导师/评审对齐"创新点落在哪里"，并作为结题报告与论文的写作施工图。
> 原则：**创新点放在"可信度"而非"能力"**；模型（38 维 + TabPFN/MIL）是**工具**，不是卖点。
> 证据分级：✅ 已完成实测 ｜ 🔧 需补实验 ｜ 📚 文献既有 ｜ ⚠️ 推断
> 日期：2026-10-10

---

## 0. 一页主张（给老师看的第一屏）

> **我们不再只问"哪个模型更强"，而是问"哪个结论可信"。**
> 本文提出两件方法：(1) **噪声分解的检出限协议（NDDL）**，用于判定因子集/模型比较的结论是否超出可分辨范围，
> 并在实验前预测"换模型是否有用"；(2) **机制分层的适用域检验**，把易发性图从"全域可用"改为
> **带适用域声明的管控图**。二者合起来交付一张**带漏检率保证、且写明适用边界**的消落带易发性图。

**为什么必须这样定位**：本项目的峰值增益是 TabPFN 相对 XGBoost 的 **+0.006 AUC**（真实、超 MDE、已排除人群混淆），
但它**不改变任何一句管理结论**。而项目中被证明能改写结论的东西，全部来自**判定口径与适用域**（见 §1）。
评审说"不要堆结构"是对的：本问题没有架构型创新的位置。

## 1. 创新点的层级

| 层级 | 创新点 | 一句话主张 | 为什么算"新方法"（而非流程/结构） | 现有证据 | 缺什么 |
|---|---|---|---|---|---|
| **主** | **NDDL：噪声分解的检出限协议** | 因子/模型比较必须先给出"最小可分辨效应"；我们把零分布方差拆成**模型侧（种子）**与**数据侧（置换）**，给出与统计量匹配的标准误、多重比较控制，并以 σ 比值**事前**预测换模型是否可能有效 | 它是一个**协议+统计量+诊断量**：有零分布、有公式、有判据；并且它**否决了领域内普遍做法**（把单次运行噪声用于卡种子均值的统计量） | ✅ 第10轮 732 次运行的 MDE 被高估 **1.0~1.9 倍**；✅ 复现其口径（0.0009/0.0016/0.0029/0.0040 vs 其 0.0010/0.0017/0.0033/0.0041）；✅ sel4 修正后（20 次置换）行政折 gap +0.0019 / t=3.78 / **p=0.035**、空间折 +0.0014 / t=1.34 / **p=0.306**，结论由"低于检出限"改写为"**检验力不足**"；✅ σ 比值：sel4 = 2.0~4.8×（换模型有用）、allgeo14 = 0.35~0.41×（换模型无用） | 🔧 **模拟研究**：注入已知 Δ，证明常规做法漏检而 NDDL 检出、假阳性受控（**这是把"修自己的 bug"升级为"方法有效"的唯一途径**） |
| **交付** | **机制分层适用域检验** | 易发性图的判别力由单一机制驱动，**图的适用域与机制域重合**；提出"先划机制域、再分层外部验证"的协议 | 把"外部验证"从"换一组点算 AUC"改为**机制域分层检验**，产出可写进管控文件的**适用域声明** | ✅ 消落带内 42 个**编目外**滑坡前10%命中 **54.8%**（样本内基准 54.7%）；✅ 消落带外：外部 39 个与编目自身 38 个**均 0.0%**；✅ 判别力 99.4% 来自 15 个水位-位置变量 | 🔧 带外样本仅 39 个（0 命中的 95% 上界≈9%）→ 补**分高程带的完整覆盖曲线**；🔧 带外机制需独立解释（不能只说"模型不适用"） |
| **交付** | **分区共形风险受控图** | 把易发性图升级为**带漏检率保证**的分区图（漏检率 ≤ α），并针对空间异质性提出**分区块校准** | 共形预测在滑坡易发性罕见；**空间分块校准 + 覆盖缺口诊断**是在既有方法上的实质扩展（全局交换性不成立时的补救） | ✅ 交叉共形 α=0.10 → 25.7% 面积、实测覆盖 88.4%（α=0.20 → 19.6%/78.7%）；✅ 校准良好（Brier 0.0233 = 可靠性 0.0002 − 分辨率 0.0023 + 不确定性 0.0252） | 🔧 量化**全局共形在分区块下的覆盖缺口**，并证明分块后闭合（半小时级，见 §4） |
| 探索 | MIL 像元袋注意力（M2） | 单元内像元级信息是否突破消落带内 0.71 天花板 | ⚠️ **gated attention 是 2018 年既有方法**，本身不算创新 | 🔧 未出结果 | 🔧 仅在消落带内子集增益 **> MDE 0.0069** 时才升格为贡献，否则写为"探索性尝试/阴性结果" |

**层级关系**：主创新（方法学）决定论文能否立住；两个交付级方法决定**你的图能不能被用**；MIL 是唯一的判决性探索实验。

## 5. 评审可能追问 & 备答

| 追问 | 备答 |
|---|---|
| **"新方法在哪？"** | NDDL 协议：零分布方差分解 + 匹配标准误 + σ 比值事前诊断；并给出模拟与实证证明常规做法会漏检（§4-E1） |
| "这不就是用现成统计量拼的吗？" | 统计工具是标准的，**新在协议与诊断量**（σ 比值可在做实验前判断"换模型是否有用"），且**实证纠正了领域内普遍做法**——这是方法学论文的常规形态 |
| "为什么不做新网络结构？" | 本项目判别力 99.4% 来自 15 个水位-位置变量，消落带内用尽全部特征仅到 0.7162 → 瓶颈是**信息集与标签量**，不是结构；换模型实测只值 +0.006，且不改管理结论 |
| "凭什么说常规做法错？" | 复现其口径（0.0009/0.0016/0.0029/0.0040）后指出：其零 SD 含种子间波动、未除以 √n，却用于卡"已平均 3 种子的 gap" → 门槛高估 1.0~1.9 倍 |
| "你的 p=0.035 算不算多重比较？" | **两种口径都报**：sel4 是**预先指定的主假设**（家族=1）→ p=0.035；若按第 10 轮"10 个臂一起测"的家族 → p_holm≈0.35。脚本输出里 family_m 已显式打印，避免误读 |
| "外部验证只有 133 个、还重叠 52 个？" | 明确写为"编目外"而非"独立"；分层后带内 42 个命中率与样本内持平（54.8% vs 54.7%），带外与编目自身一致为 0% |
| "只有正样本怎么算指标？" | 报命中率/分位数而非 AUC；并给出二项置信上界（0/39 → 95% 上界≈9%） |
| "图能用吗？" | 带适用域声明与漏检率保证：消落带内、α=0.10 时 25.7% 面积兜住 88.4% 滑坡 |
