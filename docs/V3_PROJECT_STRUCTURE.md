## 本地辅助资料

本轮将未跟踪的 22 个 tools 脚本，以及 QGIS 手动出图指南、文献分析、结题汇报资料和 QGIS 样式库归入 `archive/local_work_20261030/`，共 34 个原文件。已验证归档前后 SHA256 相同，未删除内容。

脚本覆盖五级图层导出、河道单元补全、县域统计、图层裁剪、地形阴影、等高线、东西分幅、布局模板、位置图和扩展评价等。其工作产物及原始数据仍留在原目录；没有重新执行制图或修改数据。清单见本地归档 manifest.json。归档启动器支持按原路径语义运行单个历史脚本。

`.gitignore` 明确排除本地归档和 QGIS 样式数据库；不使用 `tools/*.py` 或 `docs/*` 这类宽泛规则，避免隐藏未来实验代码。文档索引已移除远程仓库无法访问的本地文献链接。

`archive/v2/` 的既有受版本控制资料保持原状。`experiments/`、`src/` 的旧代码和旧运行脚本亦保留；若以后继续删减，需要先核对历史结果指纹、导入和测试依赖。
