# V3全部84维解释方法

本文解释对象是原2成员4000上下文的V3模型。当前屏障区主线已采用8成员1:3，其模型特定PFI/ALE尚未完成；旧结果可作为原配置的作用分析，不直接改称新主线因子贡献，见[报告证据衔接](V3_REPORT_EVIDENCE.md)。

当前运行与模型恢复统一使用[canonical入口](V3_EXPLAIN84_CANONICAL_MODEL.md)。不再启动旧`explain84`、`explain84_refit`、`explain84_saved`或`explain84_seeded`串行器。旧模型、历史评分和诊断证据保留用于恢复与对照；旧分层分页图目录已清理。

84维不是84个独立物理因子，其中包含同一地形、水位的均值、标准差、分位数和联合统计。解释对象是从保存文件加载并严格核验的固定模型，不将它称为历史评分模型的无损复现。

## 方法

- 逐维全局置换：报告AP、前20%面积清单覆盖率、AUC变化，保留各折、重复、协议与子群。
- 粗地形层内置换：高程/坡度3×3边界只拟合训练上下文；少于8单元及地形缺失层保持原值，报告实际置换比例。它是分层敏感性检查，不是精确条件重要性。
- 一阶ALE与离散/稀疏端点对比：训练侧确定范围，在有限测试支持内计算，各折保留自己的原始横轴；无支持不伪画连续曲线。
- 局部扰动：记录抽样单元原评分与随机参照替换后评分差。不是SHAP，不可加，不代表全人口逐单元贡献。
- 分层描述：结合县域、地形、水位背景、样本量、缺失与相关性理解关联；已清理旧分页图，数值分析可按需要重新生成到新目录。

默认seed42，实际模型random_state=42+fold；空间/行政各五折，4000上下文、2个estimators、batch32。抽样解释默认每折1024个测试单元、每维两次全局和两次层内置换。正式参数以canonical运行配置为准。

## 解释边界

独立加载和跨进程重载误差门槛仍为2e-5；不得刷新基线掩盖后续偏差。历史评分、保存前模型和加载后模型的完整折指标分别报告。

单列置换可能破坏相关派生量与组成约束；ALE不等于物理干预。低单维重要性不证明该因子无物理作用，需结合组级置换、相关性、样本支持与独立资料。不把模型敏感性、群体关联或粗分层曲线解释为因果贡献。
