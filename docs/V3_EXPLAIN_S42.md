# V3 seed42因子解释、空间失效与分折口径

## 本轮范围

组级解释用于补充40/48/84维控制与逐维分析。既有组级返回数值保留在`results/v3_received_explain_s42/`；旧空间失效与解释绘图目录已清理，不作为可用出图。当前84维解释模型恢复和运行见[canonical入口](V3_EXPLAIN84_CANONICAL_MODEL.md)。以下组级方法与命令仅用于需要重新核验组级实验时，不代表当前服务器正在运行它。

V3分组置换需服务器重新拟合10个84维模型：空间/行政各5折，只用实验种子42。实际模型random_state=42+fold，与原始seed42实验完全一致；4000上下文ID、数据、模型权重、缩放及事件前日期保持不变。不是重跑40/48维，也不是增加5个实验种子。

11个因子组：地形、几何、水位、水系、植被、降水、用地、道路、地质土壤、数据可用性、水位—地形联合统计。5个表征组：38维表、2个可用性指标、8均值、32分布统计、4联合统计。每一种分组视角各自覆盖84列且不重复；两种视角之间重叠，贡献不能求和。

每折固定均匀无放回抽取1024个测试单元（不按标签筛选），每组置换两次，同组所有列使用同一行置换以保留组内组合。默认共10240个被解释测试单元；可能包含较少正样本，应视为初步筛查。AUC/AP/C20下降越大，表示模型对该组信息的依赖越强，不能解释成因果效应或独立贡献。两次置换是扰动重复，不是两个模型种子或独立数据集，不据此给显著性结论。

新拟合先对这些样本的原始预测与可信V3 seed42逐单元比对，绝对误差须<=2e-5，否则停止。只校验被抽中的测试单元，不冒称重新复验全部25509单元。模型参数2个estimators、fit_preprocessors、predict_batch32保持，逐模型释放显存。子群统计为边际置换在事件前淹没子群上的读数，不是子群内条件置换。

### 重要字段准确解释

`preevent_inundation_fraction`的代码实际是各像元事件前被水位覆盖天数比例的单元均值（表格采用0.5m高程分桶），不是“曾淹没像元面积占比”。本轮字典明确其含义，没有修改该数值或既有模型。`preevent_wet_dry_transition_count`统计状态改变，不是往返循环对数；最大月变化取绝对值，包含上涨和下降。NDVI、降水、用地各自多时间尺度继承V3定义。

本次地质组仅有紫色土和T2/J2/T1比例；硬度、坡向结构、力学参数不是84维输入，不能用此解释实验宣称其物理上没有影响。

## 分折怎样产生

V3分折逐单元复制历史冻结表，40/48/84、不同模型重复种子都使用同一表，不会每次随机重划。空间折最初是在投影中心坐标上KMeans，5簇，fold_seed=42、n_init=10；历史sklearn=1.2.0，现在重新聚类可能改变少量边界单元，因此以冻结CSV为准。

行政折以完整县域为组，按各县正样本数降序，贪心放入当前正样本最少的一折。它平衡正样本，不平衡面积，县域之间不要求空间相邻；分折过程使用标签数作平衡，应在方法中如实说明。

面积是**25509个建模斜坡多边形面积之和**，总计约6248.34km²，不是整个县面积、空间簇外包络或含430河道单元的完整制图面积。两套折都没有额外空间缓冲带，边界两侧仍可能相邻，不能声称完全消除空间自相关。
