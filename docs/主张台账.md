## E. 使用说明（给合作者/导师）

1. **新想法先登记再检索**：登记后若检索发现已占，直接移入 C 区并注明"谁占的、何时"。
2. **判据先于实验**：每条主张的"被推翻的条件"必须在跑实验前写定。
3. **一篇文章一条主张**：结题报告可按"数据→处理→口径→模型→评估"组织，但论文必须 claim-first。
4. **时间戳意识**：本领域方法进口速度约两年，证据够了就先发预印本占位。
