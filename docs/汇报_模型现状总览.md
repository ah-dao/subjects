## 1. 三十秒讲完

我们用三峡库区消落带（库水位涨落的那一圈）的 **25,939 个斜坡单元**做滑坡易发性，其中 **661 个是已知滑坡**，每个单元用 **38 个特征**描述。

- **现役模型是 XGBoost**（出图口径 AUC ≈ 0.904）。它出两套结果：一套回答"**哪里易发**"（正式易发性图），一套回答"**为什么易发**"（因子归因）。
- **本轮主要收获**：TabPFN（一种表格基础模型）在出图口径下**稳定优于 XGBoost 约 0.006**，超过了我们事先设定的门槛，并且已经排除"是不是数据划分不同造成的"；但在归因口径下两者**打平**。
- **两项新能力**：① 概率可以直接当概率读；② 能给出"**划 1/4 面积，最多漏 10% 滑坡**"这种带保证的分级，可直接进管控文件。
- **三条路线被否定**：图神经网络/空间平滑（没用）、库水位时序算子（没用）、岩性硬度/坡面结构/力学参数（判别力测不出来，只留作解释图层）。
- **下一步最关键的一件事**：把 TabPFN 的全库预测结果导出——集成、不确定性、像元级新模型都在等它。

## 2. 项目底子

| 项 | 内容 |
|---|---|
| 研究对象 | 三峡库区消落带斜坡单元：25,939 个（训练用 25,509 个，已知滑坡 661 个） |
| 输入特征 | 38 个 = 地形/水位/气候植被/道路 34 个 + 精挑的地质 4 个 |
| 两套口径 | **出图口径**：全库训练，回答"哪里易发"；**归因口径**：先把地形位置配平再比，回答"为什么易发" |

一句话：**位置（相对库水位的高低）几乎决定了全部判别力**——只用 15 个位置/水位特征，就能达到 38 个特征判别力的 99.4%。
所以真正难的地方是**消落带内部**，那里的 AUC 只有约 0.71。这就是下一步要主攻的方向。

## 3. 现状一览

| 模型 / 路线 | 状态 | 一句话 |
|---|---|---|
| XGBoost（38 特征） | ✅ 现役主力 | 出图 AUC 0.904；出图与归因都靠它 |
| TabPFN v2 | ✅ 出图口径胜出（暂不换主线） | 比 XGBoost 高约 0.006，两种分折一致，已排除数据划分的干扰 |
| 概率校准 + 风险受控分级 | ✅ 已完成（T4 前半） | 概率可信；能给"最多漏多少"的分级 |
| 图神经网络 / 空间平滑 | ❌ 已否定 | 跨折后 AUC 掉到 0.45，等于没用 |
| 库水位时序算子 | ❌ 已否定 | 三种做法增量都太小，时序触发关系不成立 |
| 岩性硬度 / 坡面结构 | ❌ 不进模型 | 只作解释图层；机理上"顺向坡"仍然显著 |
| 力学参数（黏聚力/剪切力） | ❌ 弃用 | 两个参数其实是一回事，且九成可由地形算出来 |
| 像元袋注意力网络（M2） | 🔄 待跑 | 把单元看成一袋 30 米像元，唯一可能突破消落带 0.71 的方向 |
| TabPFN 压噪声门槛（T3） | ⚠️ 卡住 | 本地显卡只有 8G 显存，跑不动；修复参数已备、尚未重跑 |
| 加深模型 / 换深度表格模型 | ❌ 不做 | 加深反而变差；不换信息只换模型没有用 |

## 4. 三个主结果

### 4.1 TabPFN 在出图口径胜过 XGBoost

| 分折方式 | XGBoost | TabPFN | 差距 | 结论 |
|---|---|---|---|---|
| 按空间聚类分折 | 0.9061 | **0.9122** | +0.0061 | ✅ 超过门槛 0.0032 |
| 按县分折 | 0.9109 | **0.9163** | +0.0054 | ✅ 超过门槛 0.0019 |
| 归因口径（两种分折） | 0.826 / 0.815 | 0.830 / 0.815 | +0.005 / 0.000 | ⚪ 打平 |

两条排除性证据：

- **不是数据划分造成的**：把 XGBoost 换成与 TabPFN 完全相同的训练数据，差距几乎没变（+0.0063 / +0.0064）。
- **不是运气**：XGBoost 自己在出图口径的种子波动约 0.0004~0.0025，比 0.006 的差距小得多；TabPFN 的波动还要更小。

**处置**：先不换主线，等 TabPFN 侧改进完（含像元分支）再一次性切换；归因继续用 XGBoost。

### 4.2 概率可信 + "最多漏多少"说得清（T4 前半）

- **概率检查**：Brier 分解后"可靠性"项只有 0.0002 → **模型说 70% 的地方，真的约七成是滑坡**，不需要再校准。
- **风险受控分级**（共形预测）：**α = 10% 时，划 25.7% 的面积，能兜住 88.4% 的已知滑坡**；α = 20% 时是 19.6% 面积兜住 78.7%。
  意思是"这块区域漏掉的滑坡不超过 10%"是**有统计保证的**，不是经验估计。
- **讲法**：**"划四分之一的面积，兜住约 88% 的已知滑坡，且'最多漏 10%'有保证。"**
- **两处诚实的修正**：① 覆盖率不再"自己算自己"（改成折外验证）；② 面积-覆盖曲线原先口径偏保守（前 20% 面积实际覆盖 80.8%，不是 70.2%）。
- **两个前提要说清**：保证的是**区域整体**漏检率（不是每个单元都判对）；以**已知滑坡清单**为准。
- **后半（未做）**：等 TabPFN 的预测结果导出后，做两模型集成、单元级不确定性，并入正式出图。

### 4.3 为什么要第二套口径（归因口径）

- **问题**：全库训练时，"哪里地形像滑坡"这件事太强了——只用高程、坡度、淹没三个变量就能拿 0.8357。这样岩性、土壤、产状这些弱因子根本显不出来（这叫"混杂"）。
- **做法**：给每个滑坡单元配 5 个**地形位置相同**（高程 20 米 × 坡度 10 度同一格）的非滑坡单元，再训练一次。
- **效果**：位置差异被配平（混杂 AUC 0.8357 → 0.557），于是能回答"**同样的地形位置上，其他条件还有没有用**"。
- **代价**：它故意去掉了"位置红利"，所以 AUC 只有 0.83，**不能当管控图用**；而且只有 42.7% 的单元落在可解释范围内。
- **两套图不冲突**：一个答"哪里易发"，一个答"为什么易发"，**AUC 高低不能直接横向比**。

## 5. 三类地质变量为什么不用

**结论**：岩性硬度、坡面结构 → 只进解释图层，不进模型；力学参数（黏聚力/剪切力）→ 整体弃用。

**第一步看判别力：两套口径都没通过**

| 变量 | 出图口径的增量 | 归因口径的增量 | 判定 |
|---|---|---|---|
| 岩性硬度 | ≈ 0（两种分折还变号） | 约 +0.001 | 未通过 |
| 坡面结构 | ≈ 0（两种分折还变号） | 约 −0.002（方向是负的） | 未通过 |
| 力学参数 | 约 +0.001 | 约 +0.002（两种分折变号） | 未通过 |
| 参照：地质精选 4 维 | +0.0013 | +0.0028 | 方向为正，但也没通过 |

为什么"没通过"不等于"没用"：

- 我们能分辨的最小差异（噪声门槛）是：出图口径 0.0019~0.0032、归因口径 0.0065~0.0081。上面这些增量**全都比门槛小**，所以只能说"**没测出来**"，不能说"不存在"。
- 归因口径的门槛更大（是出图口径的 3~4 倍），所以它**更不能用来否定因子**，只用来做归因。
- 要真正测出 0.001 量级的效应，需要约 **2,500 个正样本**（现在只有 661）。

**第二步看各自的独立理由**

- **岩性硬度**：硬岩更稳定的方向是对的，但校正空间自相关后就不显著了（置信区间跨过 1）。
- **坡面结构**：机理价值最高——"顺向坡"的风险比 1.33 且稳健；但它的差别 **87% 来自区域之间的对比，只有 13% 是本地信号**，而模型已经通过地形拿到了这部分信息。
- **力学参数**：① 黏聚力和剪切力其实只有 1 个自由度（相关系数 0.9999998）；② **约九成能由地形算出来**，像是派生数据而非实测；③ 单位在源数据里是空的，没法算安全系数，也无法排除"由滑坡编目反推"的循环风险。

**一句话**：这三类变量**不是不重要，而是"重要但弱"**——它们的信息大部分已经被"相对库水位的位置"和地形承载了。

## 6. 被否定的其他路线

| 路线 | 为什么否定 |
|---|---|
| 图神经网络 / 空间残差平滑 | 用现成预测做零成本检验：邻域残差只在**同一折内**有信号（AUC 0.5453），跨折后掉到 **0.4500**，跨区域更是 −0.0004 → 它搬运的是"同一折内的错误"，不是可迁移的信息 |
| 库水位时序算子（M1） | 三种做法增量 +0.0003 / −0.0024 / +0.0009，全都低于门槛；滑坡前兆的时序关系在控制年代趋势后 **8 个滤波器 0 个显著**；也不能替代现有水位特征（−0.0061） |
| 加深/加宽 GBDT | 加深反而更差（0.9067 < 0.9093）→ 容量不是瓶颈 |
| 深度表格模型 / LLM | 和 TabPFN 用同样的信息，但更容易过拟合 |

## 8. 可能被问到（一句话答）

| 问题 | 回答 |
|---|---|
| "更优"怎么判定的？ | 同一折、同一种子配对比较；差距要**超过噪声门槛**，且两种分折方向一致 |
| 会不会是数据划分不同造成的？ | 已排除：用完全相同的训练数据，TabPFN 仍然高 0.006 |
| 会不会是运气？ | XGBoost 自己的种子波动比这个差距小得多；TabPFN 的波动还要更小 |
| 为什么归因口径 AUC 只有 0.83？ | 它故意把"位置红利"配平掉了，是更难的问题；两套口径的分值不可比 |
| 地质因子到底有没有用？ | 判别力"没测出来"（低于门槛），机理上"顺向坡"等 4 项稳健显著——两者不矛盾 |
| 岩性硬度/坡面结构/力学参数为什么不用？ | 见第 5 节：两套口径都没检出增量，力学参数另有三个硬伤 |
| 概率能当概率读吗？ | 能，校准检查显示可靠性误差只有 0.0002 |
| "最多漏 10%"是什么保证？ | 是**区域整体漏检率**的统计保证（同分布前提下），不是每个单元都判对；以已知滑坡清单为准 |
| 最大的限制是什么？ | 只有 661 个正样本，任何小于 0.001 的改进都测不出来 → 需要扩样本或提高粒度 |
| 下一步最关键的一件事？ | 导出 TabPFN 全库预测结果，它是后面所有工作的前提 |
