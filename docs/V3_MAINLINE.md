# V3当前主线与版本边界

2026-10-30起，屏障区主线采用84维TabPFN、8成员、正样本:背景=1:3子采样、seed42、固定空间五折。配置见config/v3/mainline_1to3.json。本次采用已经核验的结果，不重跑或替换旧实验。

## 数据与训练

- 屏障区25509个建模斜坡单元、661个清单滑坡单元；430个河道单元排除。当前SHP不补面、不赋最低等级，历史25939单元地图保留原身份。
- 84维=38维单元因子+2维像元可用性+44维坡内统计，不是MIL注意力编码。
- 每折从训练4折读取冻结4000名单，包含全部训练正样本，附近背景优先、远区预选。4km按质心距离计算，不使用测试折选样。
- 每成员保留全部训练正样本，再从这4000名单的背景中抽取3倍正样本数的背景，无放回、成员间可重叠；8成员集成。每折每成员总数分别为2200、2008、1944、1968、2456。
- 外部缺失填补、标准化仍在原4000上下文拟合。TabPFN8.5.0、PyTorch2.6.0+cu124、fit_preprocessors、batch32、概率平衡关闭。子采样种子42000+fold，模型种子42+fold。
- 空间折固定使用splits/v3/spatial5.csv，不新增行政五折。原行政实验是历史对照。没有额外空间缓冲带，不声称消除全部空间自相关。

## 当前结果与出图

完整空间OOF：AUC=0.913334、AP=0.187141、C20=81.69%（540/661）。只有seed42，未验证多种子稳定性。相对8成员完整4000样本，对总体指标有所改善，但AP只在2/5折提高，第0折参与过比例筛选；不写成各区域稳定提升或统计显著。

核验结果在results/v3_sampling_all4_analysis_20261030/，返回包为v3_sampling_compare_barrier_s42_all4_return.tar.gz。当前SHP为results/v3_sampling_jenks5_20261030/barrier_subsample_1to3_jenks5.shp，仅25509个模型单元，EPSG:32649。QGIS原生自然断点五级；中及以上面积24.70%、滑坡覆盖88.35%；高及以上面积14.67%、覆盖69.59%。旧图集不删除，也不再标成当前主线唯一地图。

消落区截取图继承屏障区评分及等级，不重新分级。消落区专用模型仍沿用其原配置，不因本次主线调整而自动改成1:3。它包含7101个单元、616个滑坡，不能与屏障区模型的截取结果混称。

## 运行与评价

新主线入口为`bash scripts/run_v3.sh mainline`。默认新目录、空间五折、8成员、1:3。已有完整结果无需重跑；复现时使用新目录，避免与比例列表为1:1和1:3的旧对照目录配置混用。旧train、controls和canonical入口保留原参数供历史复现，不自动变为新主线。

单折和逐折评价：AP为主、ROC-AUC及C20辅助。完整OOF自然断点分级后，再报告等级覆盖率与面积占比、固定等级边界的BA及80%/90%覆盖所需面积。县域沿用所属范围的统一断点；分母只含建模单元。评分是OOF识别结果，不解释为未来发灾概率。
