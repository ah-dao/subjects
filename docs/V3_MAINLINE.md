# V3主线与版本边界

## 研究任务与输入

研究有限训练样本和区域环境差异下，坡内信息对滑坡易发性识别的增益；空间/行政五折衡量研究区内部地域迁移，不解释为未来发灾概率。

建模25,509单元、661正样本；全图25,939单元，430河道单元按规则赋最低等级。原始标签保留，16490号排除单元的观测记录不因制图而改写。

84维输入为38维表格、2维像元可用性、44维像元统计。它们是统计特征工程，不是训练得到的注意力MIL编码器。每折固定4,000上下文，保留训练正例并按既定规则抽取负例；填补、缩放只拟合上下文。

## 版本边界

2026-10-20之前的站点与时间口径冻结为V2。V2实验不作为修正后V3结论，历史文档集中于`archive/v2/`。V3更正清溪场位置、二维椭球距离匹配，采用权威水位源和2001起至事件/折内参照月前的截断窗口；水位缺测按明确规则保留，不向过去回填未来观测。
