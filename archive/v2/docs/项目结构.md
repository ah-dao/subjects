# 项目结构（v2 主线，2026-10）

> 本文是**项目的总地图**：数据从哪来、脚本在哪、产物在哪、哪份文件是"权威结论"、哪份是"可重建的中间件"。
> 配套：`docs/README.md`（文档索引）、`docs/脚本索引.md`（自动生成，含一句话说明）、
> `docs/出图与归因_SOP.md`（操作流程与答辩口径）。

---

## 1. 一句话概览

三峡库区消落带**斜坡单元滑坡易发性**：25,939 个单元（训练 25,509）→ **38 维特征**
（34 维基础 + 4 维地质精选）→ XGBoost 5 折 OOF（AUC 0.904）→ **易发性图 + 归因 + 机理证据链**。
两套口径并行：**soft02 出图**、**matched5 归因**；地质条件既进模型（4 列）也进图层（`layers/`）。

## 2. 目录地图

| 目录 | 定位 | 内容与规模 |
|---|---|---|
| `data/` | **只读原始数据**（21 GB） | 斜坡单元 shp、DEM/地形栅格、地质图与产状/力学栅格、土壤、水系、道路、滑坡编目、逐日水位、GEE 导出 |
| `features/` | **特征层** | `v2/features_v2_train.csv`（34 维主线输入，25,509）、`features_v2_train_38.csv`（**38 维现行主线**）、`features_v2*.csv`（全量 25,939 版）、`v2/groups/*.csv`（各分组原始特征）、`v2/sources/`（GEE 矩阵缓存，172 MB） |
| `src/` | 核心库 | `config.py`（路径与超参数）、`dataset.py`（加载/分折/负采样，含 `matched_negatives`）、`metrics.py`；`model.py`+`train.py`+根目录 `train_gnn.py` 为 **v1 GNN 遗留**，不属现行主线 |
| `tills/` | **数据准备与实验脚本** | 46 个脚本，见 `docs/脚本索引.md`；`tills/shp_io.py` 是全项目统一的 shapefile 读写（**不用 geopandas**） |
| `tools/` | 一次性校验/制表工具 | `check_*.py` 完整性校验、`make_*.py` 交付字典、`make_script_index.py` 生成本索引 |
| `results/` | **结论层** | 顶层约 80 份权威报告（TXT/JSON/CSV，**只放结论**）；`results/runs/` 逐次运行的原始 JSON（`baseline/`、`r10/`）；`results/archive/` 被取代的早期报告。详见 `results/README.md` |
| `predictions/` | **出图产物** | `susc_v2_soft02.shp/.tif`（出图口径+分级）、`susc_v2_matched5.shp/.tif`（归因口径）、`contrib_decomp.shp`（三层分解 Δ）、`contrib_geo_delta.tif`、`oof_v2_predictions.csv`（全库逐折外推）、`preview_v2.png` |
| `layers/` | **地质图层产物** | `geology_units.shp`（单元级：地质类别+精选占比+易发性）、5 张与易发性同网格的分类/连续栅格、图例 CSV |
| `deliverables/` | **对外交付表** | 38 维主线表在 `features/v2/`；本目录为评审用 42/48 维表 + 中文表头 + 数据字典 + `列状态_保留与弃用.csv` |
| `docs/` | 文档 | 见 `docs/README.md` |
| `archive/` | 归档 | `v1/`（v1 全量，365 MB）、`v2_process/README.md`（2026-10 清理记录与重建方法）、`server_train_2026-09.zip`、`needs_v2_rewrite/` |

**文件生命周期规则**（清理与新增都按这个来）：

```
data/（只读，永不改）  →  features/（可重建的特征表）  →  results/runs/（逐次运行 JSON）
                       ↘  tills 脚本  →  results/*.txt|json（权威结论，保留）
                                      →  predictions/ · layers/（出图产物，保留）
                                      →  features/v2/ablation/（消融中间件，**可删可重建**）
```

## 3. 主线流水线（按顺序，全部用 `landslide` 环境）

```powershell
$py = "$env:USERPROFILE\.conda\envs\landslide\python.exe"   # 必须: 含 shapely/pyproj/rasterio/pyshp

# ① 特征层（已产出，一般不需重跑；换人口/换源时才跑）
& $py tills\v2_extract_geometry_terrain.py      # 几何 + 地形 + 高程分位
& $py tills\v2_extract_network_features.py      # 水系 3 列 + 道路 4 列
& $py tills\v2_extract_landuse.py               # CLCD 土地利用
& $py tills\v2_extract_soil.py                  # 土壤类型占比
& $py tills\v2_extract_lithology_era.py         # 岩性（手工数字化真值口径）
& $py tills\v2_extract_litho_hardness_38m.py    # 岩性硬度 4 类
& $py tills\v2_extract_slopetype.py             # 坡面结构 SlopeType
& $py tills\v2_assemble_features.py             # 汇总 34 维主线表

# ② 主线层
& $py tills\v2_build_main38.py                  # 34 + 4 = 38 维主线（含按位校验）
& $py tills\v2_ablation_r10_geology.py --calibers soft02,matched5   # 地质分组消融（可选，约 2 小时）
& $py tills\v2_ablation_r10_summary.py          # 汇总 + 检出限 MDE

# ③ 出图层
& $py tills\v2_predict_map.py --method spatial_kmeans --seeds 42,43,44   # 双口径出图 + 三层分解
& $py tills\v2_build_geology_layers.py          # 地质图层（依赖 predictions/oof_v2_predictions.csv）

# ④ 机理层（不训练模型）
& $py tills\v2_mechanism_analysis.py            # M1–M9 证据链

# ⑤ 交付层
& $py tills\make_column_status.py               # 逐列状态表（保留/解释图层/弃用）
& $py tools\make_script_index.py                # 刷新本仓脚本索引
```

> ⚠ 沙箱/受限环境下：**不要用 `n_jobs>1` 的 sklearn/joblib 并行**（会创建命名管道被拒）；
> XGBoost 自身的 `n_jobs=-1` 正常。`rasterio` 必须在 `pyproj` 之前 import。

## 4. 三套"口径"必须同时记住

| 口径 | 用途 | 权威文件 |
|---|---|---|
| **出图口径 soft02** | 正式易发性图（空间决策） | `predictions/susc_v2_soft02.*`、`results/susceptibility_map_report.txt` |
| **归因口径 matched5** | 控制地形位置后的因子归因 | `predictions/susc_v2_matched5.*`（仅 `support=1` 可解释） |
| **判别力口径（消融）** | 因子要不要进模型 | `results/v2_ablation_r10_summary.txt`（含各口径检出限） |

两条铁律：①**跨口径只能比 z 与"是否两折同号"，不能比 gap**；②**"未通过判据"≠"因子无效"**，
先看该口径的最小可分辨效应 MDE（soft02 0.0019~0.0032；matched5 0.0065~0.0081）。

## 5. 现行主线的构成（结论速查）

| 层 | 内容 | 状态 |
|---|---|---|
| 模型输入 | 34 维基础 + 4 维地质精选（`soil_purple_frac` / `litho_T2_frac` / `litho_J2_frac` / `litho_T1_frac`）= **38 维** | ✅ 主线 |
| 解释图层 | 岩性、岩性硬度、坡面结构 SlopeType、土壤类型、地质年代 → `layers/` | ✅ 交付，**不进模型**（消融 gap ≈0，但机理显著） |
| 弃用 | 黏聚力 c / 剪切力 fan（1 个自由度 + c 可由地形复现 90% + 单位不明） | ❌ 2026-10 弃用，仅留档 |
| 遗留 | v1 GNN（`src/model.py`、`src/train.py`、`train_gnn.py`）、`baseline_tabpfn.py` | ⚠ 非主线，保留作对照 |

## 6. 新人/接手者的最短路径

1. 读 `docs/README.md` → 按推荐顺序读 3 份文档（项目结构 → 出图与归因 SOP → 地质机理与消融）；
2. 跑 `tills/v2_predict_map.py` 复现出图（约 10 分钟），对照 `results/susceptibility_map_report.txt`；
3. 跑 `tills/v2_mechanism_analysis.py` 复现机理层（约 5 分钟），对照 `results/v2_mechanism_analysis.txt`；
4. 需要改特征时：改 `features/v2/groups/*.csv` → 重跑 `v2_build_main38.py` → **必须重跑第 10 轮消融**再下结论。
