# 模型创新方案与文献对照（2026-10-13）

## 结论与选择

优先级按现有数据和 10 月底初稿期限确定：

1. **水位条件下的局部响应池化模型**：月底主攻；不是泛用 MIL，应证明局部环境与水位关系在聚合前建模的价值。
2. **具有水文记忆的离散时间首发模型**：潜在贡献更强，先做数据与简单模型试验，论文完整版本可能需要延期。

二者均为待验证研究假设，检索没有证明领域首创。不建议同时做两个完整模型。纯 GNN、MoE、通用 PINN 与更换 TabPFN/KAN/Mamba 本身不作为核心创新。

## A：水位条件下的局部响应池化模型

### 问题

现有模型先把整块坡的地形平均，再与水位因子组合。库水影响可能集中在单元内少量位置；同样的均值和淹没比例，不保证水位附近具有相同坡度、粗糙度或地表条件。

假设：**先对局部环境与水位作用进行交互，再按面积聚合，能获得超过丰富统计量和普通 MIL 的空间泛化增益。**

### 最小结构

- 每单元抽取或分箱 32–64 个代表位置，输入高程、坡度、坡向、粗糙度及面积权重。优先使用现有 DEM/地形，粗尺度地质只能作为单元属性，不能虚构像元级软岩结构。
- 局部编码器共享参数，以小型 MLP（32–64 隐层）编码像元特征。
- 水位条件编码：以相对水位高程、历史淹没/出露状态、历史降幅等形成条件向量。模型先学习局部特征与条件的交互，再池化；单元基础环境另设一个小型分支。
- 输出单元级易发性分数。先独立训练，不强制依赖旧全局 OOF 底座。

可用形式：

`h_i = Σ_j a_ij · ψ(x_ij, exposure_ij)`，`p_i = sigmoid(g(h_i, static_i))`。

`a_ij` 可按面积加权，或由条件注意力学习。两者都需对照，不能将注意力的存在等同于创新。水位作用只采用软约束或有界条件结构，不把“水位越高风险必然越大”作为全局单调规律，也不把注意力解释成真实滑面或因果证据。

静态制图与前瞻预测必须分开：研究期全程水位摘要只能作为回顾性描述；若声称事件前预测，水位、植被和降雨都必须截断到统一预测时点之前。不得给正例用真实事件时点、负例随机伪时点后宣称面向固定时间的未来预警。

### 必须击败的对照

| 臂 | 用途 |
|---|---|
| 38 维 XGB 与 TabPFN | 现有强基线 |
| 丰富统计量 + XGB | 均值、标准差、分位数、极差、相对水位分箱统计；检查是否只是加入了新信息 |
| 普通平均池化/DeepSets | 检查集合输入是否已足够 |
| 普通注意力 MIL | 检查水位条件的必要性 |
| 条件局部交互 + 面积池化 | 区分局部交互与注意力增益 |
| 条件局部交互 + 条件注意力 | 最终候选模型 |

关键消融：去掉水位条件；将局部坡度/粗糙度与高程位置的配对随机重排（保持各自边际分布）；不同袋容量；小样本学习曲线。不能仅打乱整行像元顺序：集合池化对这种操作天然不变。

第一阶段若地形像元提取受阻，可用现有 `elev_pairs.npz` 的高程分布做条件分箱原型。但只有高程分布时，不能宣称学到了坡体内部的空间排布或地质共址。

### 贡献成立条件

两套空间/行政验证中方向一致；消落带内指标与固定面积覆盖改善；相对“丰富统计量 + XGB”和普通 MIL 仍有可信增益；移除条件交互后增益衰减。全域 AUC 小幅提高但带内无增益，不足以支持机制主张。

历史 MDE=0.0069 只能用于规划，不是新模型的通用显著性门槛。按本次配对预测和空间块重采样重新估计区间，预先指定主指标。

## B：具有水文记忆的离散时间首发模型

### 问题

现有静态二分类把 2003–2021 的首发事件压为一个标签，事件日期和水位过程的对应信息利用不足。此前固定水位算子未检出增益，否定的是已试验的固定摘要族，不能直接否定可学习历史响应；但也要求新模型必须用强摘要对照。

假设：**历史水位驱动的暴露状态及其滞后响应，与局部静态环境共同决定首发事件的条件风险；共享少数响应时间尺度可改善跨年份预测。**

### 结构与样本

1. 每单元每月构造风险集，未首发者继续进入，首发之后退出。无研究期事件者暂按右删失处理；在编目不完整时，解释为“首次记录事件”，不能声称真实首次失稳。
2. 由高程 CDF `F_i` 与站点水位形成暴露历史 `u_i,t=F_i(H_s,t)`；增加涨落方向与历史降雨输入。
3. 小型共享记忆层：`m_i,t = ρ_i m_i,t−1 + (1−ρ_i) u_i,t`，`ρ_i=exp(−Δt/τ_i)`。先固定 τ 或使用 2–3 个共享尺度，再考虑由地质类别调节；不要为 661 个事件拟合每坡独立参数。
4. 条件事件概率：`h_i,t=P(T_i=t | T_i≥t, static_i, history_<t)`，用离散时间生存似然拟合。预测只能使用 t 之前可获得的数据；若使用当月实测水位，必须称为当月回顾性评估而非提前预测。

这里的记忆状态是暴露/响应代理，不能称真实孔隙水压，也不能把估计 τ 当作渗透系数。本项目缺孔压、土层厚度和可信力学参数，不宜直接包装成 Richards 方程 PINN。

### 对照与评价

- 简单离散时间逻辑/GAM 模型；相同风险集上的 XGB。
- 静态环境 + 日历/蓄水阶段基线，防止模型只学 2003–2009 的事件集中。
- 固定历史窗口摘要 + XGB；同输入的小型 GRU/TCN。
- 无记忆、固定 τ、可学习共享 τ 三臂；去掉水位、去掉地质调节。
- 外层按未来年份留出，再增加县/河段空间留出；训练内调参，避免同单元跨随机时间拆分。
- 月风险 PR-AUC、时间依赖 AUC、Brier/校准、固定巡查预算覆盖；与静态模型比较时统一时间范围和事件定义。

### 数据前置与限制

已有逐日站点水位、单元高程像元、月雨量源矩阵与首发日期。但需核定：历史日期可靠性、2003 前已有滑坡单元是否仍在风险集、编目截至日期是否代表持续观测、2003 年初水位序列是否与原始站点记录一致、早期降雨与植被缺失。

多出几百万单元—月份行不等于增加了独立滑坡事件；有效标签仍稀少。应使用简约模型、共享参数和年份外推评价。

## 现有代码必须先修正的地方

- `v2_model_mil.py` 读取了像元特征 `X`，但没有把袋内 `row/col` 送进模型。现版本无法检验空间排布。
- 单元袋与表格标准化均在全人口上拟合，应在各外层训练折内拟合。
- 固定全局 OOF 作为残差输入不保证外层隔离：对某训练行生成 OOF 的底座可能训练过当前外层测试折标签。若保留融合，应在外层训练集内生成内层 OOF，再用外层训练底座给外层测试集预测。
- 训练/测试袋抽样需固定并记录；检验无像元单元与面积权重，保证重复抽样不改变面积语义。
- 同一像元的特征与坐标必须一起管理；空间关系消融应改变配对，而非列表顺序。
